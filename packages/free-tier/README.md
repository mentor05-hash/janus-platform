# 무료판 고지·워터마크 조각

배치표 생성기가 빌드 시 `require` 해서 무료판 산출 HTML 에 삽입하는 조각. 백로그 **B012**, 점검표 **§2·§3·§4**.

생성기(`gen_jeongmil.cjs`)가 아직 repo 에 없어도 이 조각은 독립적으로 완성·검증된다 — 반입되면 붙이기만 하면 된다.

## 쓰는 법

```js
const D = require('../../packages/free-tier/disclosure.cjs');

// 한 번에
html = D.injectAll(html, {
  basedOn: '2026학년도 기준',
  sourceNote: '공개된 입시 결과 통계',
  generatedAt: '2026-07-26',
  // logEndpoint: 'https://…/free-log',  // 보관기간 정책(B015) 확정 후에만
});

// 또는 조각별로
html = html
  .replace('</head>', D.headCss() + '</head>')
  .replace('<body>', '<body>' + D.watermarkHtml())
  .replace('</body>', D.footerHtml({ basedOn: '2026학년도 기준' }) + '</body>');
```

삽입 후 반드시 게이트를 돌린다 — 삽입 누락을 사람이 눈으로 잡지 않게:

```bash
./ops/publish-gate.sh <산출_디렉터리>
```

## 설계 판단 (왜 이렇게 만들었나)

| 결정 | 이유 |
|---|---|
| 워터마크를 `position:fixed` 오버레이가 아니라 **본문 뒤 레이어**(absolute, z-index 0)로 | fixed 오버레이는 긴 페이지에서 스크린샷에 한 장만 찍히고 인쇄에서 사라지는 경우가 많다 |
| `@media print` 에서 워터마크 **유지 + 불투명도 상향** | 화면에만 있으면 PDF 저장·인쇄본 재배포를 막지 못한다(점검표 §3-1) |
| 면책 고지를 **결과 카드 바로 아래**, 본문과 같은 크기로 | 푸터 최하단 8px 회색은 점검표 §2-3 **미통과** 기준이다 |
| 면책 문구에 3요소 고정 | ①통계적 추정·합격 미보장 ②기준 시점 ③최종 판단은 이용자 책임 — §2-2 요구사항. 문구 수정 시 3요소 유지 확인 후 §2-2 재판정 |
| 워터마크에 `aria-hidden` | 스크린리더가 워터마크를 본문으로 반복 낭독하지 않게(접근성) |
| 접속로그는 **엔드포인트 없으면 아무것도 하지 않음** | 보관기간 정책(B015)이 정해지기 전에 수집을 시작하지 않는다. 수집 실패는 페이지 동작에 영향 없음(맥이 꺼져 있어도 무료판은 서빙되므로 실패가 정상 상황) |
| 로그에 IP·식별정보 미수집 | 경로·유입 호스트·화면폭·타임스탬프만. §4-2 |

## 검증 기록 (2026-07-26)

- `node --check` 통과.
- **게이트 전후 대조**: 조각 삽입 전 산출물 → 면책·워터마크 2건 미통과(exit 1) / 삽입 후 → 전 항목 통과(exit 0).
- 375px 실렌더 캡처: 워터마크가 콘텐츠 뒤에 보이고, 면책 박스가 결과 카드 바로 아래에 위치. 한글 어절 단위 줄바꿈(`word-break: keep-all`) 정상.
- 인쇄(PDF) 출력에 텍스트 렌더 확인(382개 텍스트 오퍼레이터) — 워터마크·고지가 인쇄본에 남는다.

## 남은 것

- 생성기 반입(B009·B010) 후 실제 산출물에 배선 + 점검표 §2·§3 전 항목 판정.
- 접속로그 수신 엔드포인트: 보관기간·파기 정책(B015) 확정 후 추가.
- 워터마크 제거 난이도(§3-3)는 사람 판정 항목 — 개발자도구로 레이어를 지웠을 때 데이터가 남는지 확인해 기록한다. 이 조각은 **데이터 보호가 아니라 재배포 억제** 수단이다(회원 데이터 자체는 산출 단계에서 제외하는 것이 방어선 — §1-1).
