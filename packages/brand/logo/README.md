# 야누스 로고 — 정본 마크

정본 출처: `docs/90_archive/legacy_reports/야누스_메인랜딩_디자인프롬프트_2026-07-06.md` 부록("확정 로고 SVG — 이 마크 사용").
배치 근거: 디자인통합 지시서 스텝 1 — "확정 아치문 SVG를 정본으로 라이트/다크 2종을 `packages/brand/logo/` 에 배치".

| 파일 | 용도 |
|---|---|
| `janus-mark-light.svg` | 밝은 배경 |
| `janus-mark-dark.svg` | 어두운 배경 — 네이비 면을 한 단계 밝히고 은빛 요소를 밝게. 형태·대칭은 정본과 동일 |

## 의미

좌우 대칭 **아치문**. 왼쪽 **네이비** = 과거·치열한 현재, 오른쪽 **골드** = 미래·안정된 미래. 상단 **두 개의 흰 점** = 두 얼굴. 상단 은빛 이맛돌, 하단 은빛 받침.

## 사용 규정 (위반 시 오용)

- **눈동자(동공)를 넣지 않는다.** 두 흰 점은 채워진 원 그대로 둔다.
- **좌우 대칭을 유지한다.** 좌우 색을 바꾸거나 한쪽만 쓰지 않는다.
- **여백은 문턱 바(하단 받침) 높이 이상**을 확보한다.
- **비율 왜곡·임의 색상·회전·그림자/발광 등 효과 금지.**
- 워드마크를 함께 놓을 때: 밝은 배경 = 네이비 워드마크 / 어두운 배경 = 흰색 워드마크.
- 워드마크 서체는 Pretendard(한글). SVG에 텍스트를 굽지 않고 앱에서 조판한다 — 서체 미설치 환경에서 렌더가 달라지는 것을 막기 위함.

## 아직 안 된 것

- 디자인 토큰 단일 소스(`packages/brand/tokens.css` · `tokens.json`)는 **미생성** — 디자인통합 스텝 1 범위(백로그 B037·B038과 함께 처리).
- 앱 적용(`branding.config.json` 의 `logoMark` 는 현재 텍스트 글자 `"멘"`)은 도메인·번들ID 확정과 함께 처리 — 백로그 **B011**.
- 마케팅 정적 페이지(`apps/web/public/site/*.html`)는 잇올 잔재로 **rebuild 대상**이라 이 마크를 지금 끼워넣지 않는다 — 백로그 **B044**(N3 관문 홈 이식)에서 신규 마크업과 함께 적용.
