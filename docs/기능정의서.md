## 1. 서비스 개요

입시학원의 **선생님–학생 1:1 멘토링/상담 예약 플랫폼**. 진단(배치표·수준진단) → 처방(커리큘럼) →
실행(Q&A·상담·과외·클리닉·강의) → 통과(합격)의 전환 관문. 학생이 상담 유형·방식·선생님을 선택해
예약하고, 크레딧으로 결제하며, 상담 기록·리포트·성적·평가·급여까지 운영 전 과정을 지원한다.
웹(선생님·관리자·학부모 콘솔) + 모바일(학생·학부모·선생님) 이원 클라이언트.

### 1.1 역할(6종)과 권한 레벨
| 역할 | 클라이언트 | 권한 | 설명 |
|---|---|---|---|
| 학생(student) | 모바일·웹 | — | 상담 신청·크레딧·성적·질문·리그 |
| 학부모(guardian) | 모바일·웹 | — | 자녀 연결·상담열람·리포트 수신·결제(대납) |
| 선생님(teacher) | 웹·모바일 | — | 상담 수행·기록·리포트·평가·급여·성과 대시보드 |
| 센터관리자(admin, 센터소속) | 웹 | L3 | 자기 센터 운영·정책·대시보드·**자기 센터 지표** |
| HR(hr) | 웹 | L2/L3 | 등록·승인·명부 일괄등록 |
| 본사관리자(admin, 센터 미소속) | 웹 | L1/L2 | 전 센터·전사 정책·노출 제어·**전체 지표** |

### 1.2 아키텍처 계층
- **L1 코어**: 계정·SSO·결제·실시간·티어 게이트(공통 기반).
- **L2 공통 데이터 규약**: `janus_score`(성적 v22 규약)·`janus_report`(진단·격차·추천 표준 산출물) — 도구 간 자동 연동의 계약. 목표 대학·배치라인은 성적 도메인에 포함.
- **L3 서비스**: 상담·과외·강의·컨설팅·QnA·커뮤니티 등 실행 제품군.

## 2. 핵심 도메인 불변규칙 (필수 구현·테스트)

- **INV-1 휴게 버퍼**: 모든 예약 앞뒤 각 10분. 유효 슬롯 = 학생 체류 ∩ 선생님 근무 ∩ (예약·버퍼 제외).
- **INV-2 요금 단일 소스**: `pricing-policy`만 요금 정의. `cost = round(perHour × min ÷ 60)`, S급 할증.
- **INV-3 크레딧 소비 순서**: 주간부여분(만료임박) → 구매분. 부족 시 차단 + 결제요청.
  월요일 00:00 부여 / 일요일 24:00 소멸(이월 없음).
- **INV-4 예약 상태머신**: `new→confirmed→done` + `cancelled/rejected/noshow`, 역상담=`reverse`.
- **INV-5 상담기록 공개**: 메모만 내부. 핵심요약·숙제·향후방향은 학생·보호자 공개. 완료는 final 저장 필요.
- **INV-6 취소·환원**: 선생님 사유 취소 시 대체후보·알림·크레딧 환원.
- **INV-7 가중 제한**: 당일취소·노쇼·과다거절 임계 초과 → 신규 신청 제한 + 랭킹 하락.
- **INV-8 카테고리×방식**: 상담유형별 허용 방식은 정책, 기능 열기/닫기는 FeatureAvailability(전사>센터).
- **INV-9 민감정보**: 인적사항·상담내용·결제·급여는 DB에만, 저장소엔 더미. 응답 권한별 마스킹.
- **INV-10 상담 리포트·미디어 게이트**: 상담 리포트(2뷰)는 선생님 **검수→승인→발송**을 거쳐야 학생 노출.
  발송 후 재발송 불가(조건부 상태전이). 상담 녹음·AI 요약은 **보호자 동의 자녀 한정**, 음성 원본은
  보존기간 후 자동 파기. **미성년 학부모 대상 직접 push 금지** — 계정 내 열람 + 학생 주도 공유가 기본 전달 경로.
- **INV-11 관측 지표 무개입·센터 격리**: tutor_source·만족도·추천 효과 지표는 **읽기 전용 관측**으로
  정산 금액·매칭 로직에 개입하지 않는다. 지표는 **본사=전체 / 센터관리자=자기 센터**로 fail-closed 격리.

| 토큰 | URL 쿼리 토큰 금지 — embed 는 fragment(#) + history 스크럽. refresh single-flight(웹). SSO 토큰 상수시간 검증·epoch 일괄 폐기 |
