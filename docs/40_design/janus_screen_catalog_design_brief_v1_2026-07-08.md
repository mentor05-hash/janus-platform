# 야누스 화면 종합 카탈로그 — 클로드 디자인 업무지시 v1 (2026-07-08)

> **기존 브리프(`janus_ui_redesign_brief_2026-07-08.md`)의 확장판.** P0 4종(디자인 시스템·관문 홈·Q&A 3화면·격차 리포트)은 기존 브리프 프롬프트를 그대로 사용하고, 본 문서는 ①프로젝트 전체 화면의 카탈로그(코드 실측: 웹 64라우트·모바일 ~47화면) ②화면별 상세 명세 ③웨이브 B~D 붙여넣기용 프롬프트를 제공한다.
> 공통 제약(전 웨이브): 산출물 **영문 파일명** · **"잇올" 명칭 금지** · localStorage 등 브라우저 저장 API 미사용(정적 목업) · 각 화면에 타이포 명세+반응형 브레이크포인트 주석 · 라이트/다크 모두.

## 1. 디자인 시스템에 반드시 포함할 공통 컴포넌트 (코드 계약과 1:1)

아래 컴포넌트는 백엔드/스니펫 계약이 이미 확정돼 있어, 디자인이 이 구조를 따라야 코드 반영이 1:1로 된다.

| 컴포넌트 | 계약(코드 필드) | 사용처 |
|---|---|---|
| **커리큘럼/처방 카드** | `{title, description, service, href, ctaLabel}` (GatewayCard) | 관문 홈 답변·격차 리포트 처방·학부모 주간 리포트 — **한 컴포넌트로 3곳 공용**, 도메인 아이콘 슬롯만 교체 |
| **AI/근거 출처 배지** | `source: 'llm'\|'rules'` → "AI 해석" vs "기본 추천" | 관문 홈 해석 결과 상단 |
| **성적 연동 배지** | `"성적 연동: {period} · {OCR\|수동 입력\|엑셀}"` | 배치표·수시 도구 우상단(스니펫이 자동 표시 — 스타일만 디자인) |
| **신뢰도 배지** | `relTier: A\|B\|C` + `{label, value, source}` | 격차 리포트 근거 수치마다 부착. "근거 없는 수치 금지"가 규칙 |
| **AI 답변 라벨 3종** | `ai / ai_assisted / human` | Q&A 답변 카드 — 색+아이콘, 색맹 대응 |
| **티어 게이트 잠금** | `tier: free<member<paid<consultant` | 배치표 회원 구간·유료 기능 — 잠금 카드+"플랫폼 계정으로 열기"(SSO) 버튼 |
| **상담 방식 아이콘 5종** | `board(보드)·chat(채팅)·zoom(줌 화상)·hand(필기)·offline(대면)` | 예약·매칭·인박스·선생님 프로필 전반(코드 enum과 라벨 고정) |
| **신호등 4구간** | 안정/적정/소신/상향 — 차분한 채도(빨강 과다 금지) | 배치표·격차 리포트 |
| **상태칩** | 기존 토큰 존재: new/confirmed/done/muted/danger | 예약·질문 상태 전반 |
| **등급 배지** | S(골드 그라데이션)/A/B — 기존 `--grade-*` 토큰 계승 | 선생님 평가·프로필 |
| **CTA 계측 슬롯** | 모든 주요 CTA에 `data-janus-cta` id 명기(예: `consult-reserve`) | 목업 주석으로 CTA id 표기만 해주면 코드에서 배선 |

기존 토큰 참고(계승·확장): 웹 `tokens.css`(CSS 변수, 다크 `data-theme`)·모바일 `SP{4,8,12,16,24}`/`R{7,9,14,999}` 스케일 — **간격·라운딩 스케일은 모바일 것을 전 플랫폼 표준으로 승격**.

## 3. 우선순위 웨이브

- **Wave A = 기존 브리프 P0 4종** (디자인 시스템·관문 홈·Q&A 3화면·격차 리포트) — 기존 프롬프트 사용.
- **Wave B = 학생 코어 루프** (아래 프롬프트 B): 나의 관문 대시보드·선생님 검색/프로필 카드·예약 플로우·세션 3종(채팅/화이트보드/화상)·멤버십/크레딧.
- **Wave C = 공급·관리 밀도 화면** (프롬프트 C): 선생님 인박스+답변 큐+대시보드·학부모 5탭(+주간 리포트 카드)·관리자 공통 셸+퍼널 통계+SSO 레지스트리.
- **Wave D = 확장 팩** (프롬프트 D): 커뮤니티/3부 게시판·리그 배지·수준 진단·서비스 허브 리뉴얼·B2B 섹션.
