## ■ 붙여넣기용 프롬프트

당신은 프로덕트·브랜드 디자이너입니다. **야누스(Janus) — "미래를 여는 문"**: 진단(배치표·수준진단) → 처방(맞춤 커리큘럼) → 실행(Q&A·상담·과외·클리닉·강의) → 통과의 루프를 제공하는 **전환(轉換) 관문 플랫폼**의 앱/웹 UI를 전면 개편해 주세요. 기존 UI를 유지할 필요 없습니다. 아래 IA·원칙에 따라 **디자인 시스템 1식 + 핵심 화면 목업(P0 우선)**을 라이트 목업(HTML 또는 SVG, 데스크톱+모바일)으로 제안해 주세요.

### 1. 사업 맥락 (디자인이 풀어야 할 문제)

- 고객층이 다층적입니다: **학생(중·고 전학년, 모바일 중심) · 학부모(결제 결정권자, 가독성 중시) · 선생님/컨설턴트(공급자, 정보 밀도) · 학원/교육기업(B2B)**.
- 서비스가 계속 늘어납니다(배치표 → Q&A → 상담 → 과외/클리닉 → 강의/VOD → 컨설팅 → 이후 멘탈 코칭·커리어 등). **새 서비스가 추가되어도 첫 화면과 내비게이션이 재설계되지 않는 확장 구조**가 최우선 요구입니다.
- 초기 최대 수요는 **Q&A(질문 게시판)**로 예상: "사진 한 장으로 질문 → AI 초안 즉시 + 선생님 답변"이 가장 마찰 낮은 진입입니다.

### 2. 채택할 IA — "관문 우선 + 역할 적응형" 하이브리드

- **비로그인 첫 화면 = 관문 홈(기존 시안 계승·발전)**: 중앙에 큰 질문 **"무엇을 준비하고 있나요?"** + 자유서술 입력 + 예시 칩. 그 바로 아래 **즉시 행동 타일 3개**:
  ① **성적으로 진단받기**(성적표 사진 OCR/직접입력 → 배치표·격차 리포트)
  ② **질문 올리기**(Q&A — 사진 한 장이면 AI 초안이 즉시 달림)
  ③ **선생님 찾기**(상담·과외 매칭)
  역할 선택을 첫 화면에서 강요하지 않습니다(구 역할형 랜딩의 4카드 방식 폐기). 학부모·선생님·학원은 헤더의 보조 진입("학부모이신가요?" / "가르치러 오셨나요?" / "B2B")으로.
- **로그인 후 = "나의 관문" 대시보드(역할 적응)**: 모든 역할이 같은 프레임 — 상단 **[지금 위치(진단 상태) → 다음 할 일(커리큘럼/일정) → 바로가기(내 서비스)]** 3단. 역할에 따라 내용만 바뀝니다(학생=격차·오늘 할 일·내 질문 / 학부모=자녀 리포트·결제 / 선생님=인박스·오늘 일정·답변 큐·예상 정산).
- **하단 탭(모바일) 5개 고정**: 홈(관문) · 질문(Q&A) · 진단(배치표/리포트) · 일정(상담·수업) · 내정보. 새 서비스는 홈의 커리큘럼 카드와 "허브"로 흡수 — 탭을 늘리지 않습니다.

### 3. 디자인 원칙 5 (심사 기준)

1. **관문 우선**: 어떤 화면에서든 "다음 문(다음 할 일)"이 가장 크고 명확하게. 막다른 화면 금지 — 항상 다음 행동 1개를 제시.
2. **근거가 곧 신뢰**: 수치에는 근거 배지(예측 신뢰도, 실측 기반, 풀별 평균 응답시간)와 면책을 **디자인 요소로** 내장. 론칭 시안의 "정밀 인스트루먼트" 톤(모노 숫자·데이터 밀도)을 진단 화면에 계승. 불안 조장 비주얼(경고 남발·빨강 과다) 금지 — 신호등 4구간(안정/적정/소신/상향)은 차분한 채도로.
3. **대상별 친화**: 학생=모바일 퍼스트·한 손 조작·큰 터치 타깃, 학부모=본문 17px+·고대비·전문용어 풀어쓰기, 선생님=데스크톱 밀도·큐 처리 효율, B2B=별도 랜딩 섹션.
4. **AI 투명성**: AI 생성/AI 보완/사람 답변을 즉시 구별하는 라벨 체계(색+아이콘, 색맹 대응)를 시스템 컴포넌트로.
5. **팩 확장성**: 서비스 카드·커리큘럼 카드·배지·리스트가 버티컬이 늘어도(멘탈·커리어 등) 같은 컴포넌트로 수용되도록 — 컴포넌트에 도메인 색·아이콘 슬롯만 교체하는 구조.

### 4. 산출물 (우선순위)

**P0 — 내일 필수 4종**
1. **디자인 시스템 1페이지**: 컬러 토큰(네이비 `#24405f`·골드 `#cf9a3a`·블루 `#2f6fb3`·실버 `#c7ccd2` + 신호등 4색·AI 라벨색), 타이포(산세리프 2굵기, 모바일/데스크톱 스케일), 버튼·카드·배지·입력·탭·별점 컴포넌트, 라이트/다크.
2. **관문 홈 리뉴얼**(비로그인, 데스크톱+모바일): §2 구조. 히어로 배경은 첨부 4방향 중 **딥 네이비 포탈 또는 여명 라인 중 택1**로 발전(시인성 최우선 — 헤드라인 고대비, 미세 스크림 허용), 확정 아치문 로고 사용(두 흰 점, 눈동자 없음).
3. **Q&A 플로우 3화면**: ⓐ 질문 작성(사진/PDF 첨부 중심, 스코프 선택: 전체 공개/내가 고른 선생님만("응답이 느릴 수 있어요" 고지 칩)/특정 선생님 지정) ⓑ 답변 보기(AI 초안 라벨 → 선생님 답변, 별점+"이 선생님에게 계속 받을까요?" 2문항) ⓒ 후속 액션 시트(**[채택] [다른 선생님에게 재답변 (남은 2회)] [이대로 상담 이어가기 →채팅/화이트보드/화상]** — 재답변 잔여 횟수 표기).
4. **격차 리포트**(진단 결과): 현재 위치 → 목표까지 격차 → 근거(신뢰도 배지·다년 추세 미니차트) → 처방 CTA 3개(상담/클리닉/강의). "무료로 할 수 있는 것" 섹션 포함.

**P1 — 여력 시**: 나의 관문 대시보드(학생/학부모 2변형), 선생님 프로필 카드(풀별 응답시간·만족도 배지, 단골/차단은 학생만 보이는 UI), 커리큘럼 카드 리스트.
**P2 — 차회**: 선생님 홈(답변 큐+인박스), 강의실 학생 화면 스킨, 티어/멤버십 페이지.

### 5. 카피 톤

- 태그라인 유지: "미래를 여는 문" / "치열한 현재에서 안정된 미래로".
- 데이터로 통념을 교정하는 어조(예: "작년 70%컷은 '안정'이 아닙니다 — 실제 합격률 37%"). 단정 대신 근거, 공포 대신 다음 행동.

### 6. 제약

- 모든 내보내기 **영문 파일명**(예: `janus_home_v1.html`, `janus_qna_flow_v1.html`, `janus_design_system_v1.html`, `janus_gap_report_v1.html`).
- 산출물에 "잇올" 명칭·구 브랜드 요소 금지. localStorage 등 브라우저 저장 API 미사용(정적 목업).
- 각 화면에 타이포 명세(굵기·크기·대비)와 반응형 브레이크포인트 주석 포함.
