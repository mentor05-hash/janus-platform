## 개념
공급자(선생님)의 하루 시작 화면. 3블록 요약 — **오늘 일정 · 답변 큐(Q&A) · 예상 정산**. 처리 효율(수락/거절·클레임)과 SLA 가시성 중심. 인박스(예약 큐)·답변 큐(WB-10)로 진입.

## 구성 (3블록)
1. **오늘 일정** — 예약·강의 타임라인, 상담방식 아이콘 5종, 공백/강제배정 표시.
2. **답변 큐(Q&A)** — 클레임 잠금·타임아웃 카운트다운·풀별 SLA(0051 claimed/first_reply/resolved). 재답변 사유 힌트. → WB-10 답변 큐로.
3. **예상 정산** — 건당 단가 누계(상담·Q&A), 등급 수당. 급여 상세로.

## §1 컴포넌트 계약 대조표
| §1 계약 | 이 화면 적용 | 확인 |
|---|---|---|
| 상담방식 아이콘 5종 `board·chat·zoom·hand·offline` | 오늘 일정·큐 항목 | ✅ |
| 상태칩 new/confirmed/done/muted | 예약·질문 상태 | ✅ |
| 등급 배지 S/A/B | 프로필 요약(§B 검색 카드와 동일 컴포넌트) | ✅ |
| SLA(0051) claimed_at·first_reply_at·resolved_at | 답변 큐 블록 카운트다운·풀별 | ✅ |
| CTA `data-janus-cta` | "답변하기"=`answer_open` · "일정 관리"=`schedule_open` | ✅ |
> ⚠ 정산 수치는 예시(비식별). 급여 단가는 정책값(ENV/pricing-policy) 참조 — 하드코딩 금지.

## CTA 위계
골드 = 최우선 액션(대기 답변 처리) `data-janus-cta="answer_open"`. 블루 = 일정·정산 이동. 회색 = 필터.
