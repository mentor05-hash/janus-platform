# 야누스 메인 랜딩(히어로) 디자인 프롬프트 — 클로드 디자인용

> 이 문서를 붙여넣으세요. 개인 프로젝트입니다. **산출물에 "잇올" 명칭 금지.**
> 첨부: `야누스_메인시안_로고적용_4종.png`(4방향+로고), `야누스_로고_확정_라이트.png`, `야누스_로고_확정_다크.png`.

## ■ 붙여넣기용 프롬프트

당신은 브랜드·웹 디자이너입니다. **야누스(Janus) — "미래를 여는 문"**, 진로·입시를 준비하는 모두를 위한 관문 플랫폼의 **메인 랜딩(히어로)** 를 디자인해 주세요. 화면 중앙에 큰 질문 **"무엇을 준비하고 있나요?"** 와 검색 입력창이 있는 관문형 진입입니다. 아래 4가지 배경 방향과 **확정 로고**를 얹어, **시인성(가독성)을 확실히 높인** 히어로 시안을 방향별로 라이트 목업(HTML 또는 SVG)으로 제안해 주세요.

## 1. 문제 / 목표

- 현재 히어로가 **시인성이 부족하고** 원하던 웅장·아스피레이셔널한 느낌이 덜합니다.
- 목표: **헤드라인이 또렷하게** 읽히고(굵고 크게·고대비, 필요시 미세 스크림), 배경은 "하늘로 열린 관문"의 광활함을 담되 텍스트를 방해하지 않을 것.
- 첨부 `..._로고적용_4종.png`가 시작점입니다(로고 좌상단 배치 + 큰 헤드라인 + 검색창). 이 완성도를 프리미엄으로 끌어올려 주세요.

## 2. 배경 방향 4종 (택1~2 발전, 자유 변형 가능)

- **A. 블루 스카이 아치** — 파란 하늘·구름 위 흰 석조 아치. 크리스프 네이비 헤드라인. (가장 광활)
- **B. 옐로우 관문 창** — 밝은 옐로우 벽에 뚫린 아치 창으로 하늘. 골드 브랜드 전면·경쾌.
- **C. 여명 그라디언트 + 라인 아치** — 새벽 그라디언트, 얇은 라인 아치. 차분·프리미엄.
- **D. 딥 네이비 포탈** — 밤하늘/우주에 빛나는 문. 몰입감(단, 헤드라인 또렷).

## 3. 확정 로고 (반드시 이 마크 사용)

- 좌우 대칭 **아치문**: 왼쪽 **네이비**(과거·치열한 현재), 오른쪽 **골드**(미래·안정된 미래). 상단에 **두 개의 흰 점(두 얼굴)** — ⚠**눈동자(동공)는 넣지 말 것**. 상단 은빛 이맛돌·하단 은빛 받침.
- 배경이 밝으면 워드마크 네이비, 어두우면 흰색. 부록 SVG 참고.

## 4. 브랜드 스토리 (분위기·카피에 녹일 것)

- 야누스 = 로마신화 **문의 신**, 두 얼굴로 **과거를 통찰하고 미래를 응시**. **전쟁과 평화의 신**(신전 문을 전쟁 때 열고 평화 때 닫음).
- 번역: 입시는 지금 **치열한 현재** → 야누스는 지난 데이터를 읽어 문을 열고 **안정된 미래**로 잇는다.
- 태그라인: "미래를 여는 문" / "과거를 통찰하고, 미래를 응시하다" / "치열한 현재에서 안정된 미래로".

## 5. 유지할 UI

- 큰 검색 입력창 + [길 찾기] + 예시 칩(정시/수시/성적/자소서/재수/학부모). 한 줄 적으면 맞춤 커리큘럼으로 이어짐.
- 히어로 아래로: 여정(묻다→진단→커리큘럼→통과) · 기대효과 · 서비스 허브(멘토링 중심 8종). 이 하부는 유지·조화.

## 6. 브랜드 컬러 / 타이포

- 네이비 `#24405f` · 골드 `#cf9a3a` · 블루 `#2f6fb3` · 실버 `#c7ccd2`.
- 헤드라인: 굵은 산세리프, 큼직하게, 고대비. 자간 정밀. 두 굵기만.

## 7. 산출물

- 방향별 히어로 시안(라이트 목업), 반응형(데스크톱·모바일), 헤드라인 타이포 명세(굵기·크기·대비), 배경 은은한 모션(구름 표류 등) 제안. 텍스트 가독성 최우선.
