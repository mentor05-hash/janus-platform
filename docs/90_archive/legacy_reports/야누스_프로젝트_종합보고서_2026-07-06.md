## 0. 한눈에

- **제품명 야누스(Janus)** — "미래를 여는 문". 진로·입시를 준비하는 모두를 위한 **관문 플랫폼**. 개인 사이드 프로젝트로 **잇올과 분리**(야누스 브랜딩에 잇올 명칭 미사용).
- 두 개의 축이 합쳐진 프로젝트:
  1) **입시 데이터 도구군** — 정시 합격예측/배치표(핵심), 수시 입결 인터랙티브, 반영교과 등급 계산기 등. (실측 데이터 + 예측 알고리즘)
  2) **통합 멘토링 플랫폼(야누스)** — 상담 매칭 중심으로 여러 서비스를 잇고, "무엇이 필요한가"를 물어 맞춤 커리큘럼을 추천하는 관문형 홈.
- 배포는 **무료/회원/유료/컨설턴트 4단계**(티어별 별도 빌드). 인프라는 맥미니 + Cloudflare Tunnel 하이브리드 계획.

## 1. 브랜드 (야누스)

- **의미:** 로마신화의 **문(門)·시작·전환의 신**, 1월(January)의 어원. **두 얼굴로 과거를 통찰하고 미래를 응시**한다(역사를 읽어 미래를 준비하는 지혜). 또한 **전쟁과 평화의 신** — 신전의 문을 전쟁 때 열고 평화 때 닫았다.
- **브랜드 번역:** 두 얼굴 = **과거 데이터로 미래를 예측**(우리 배치표의 본질). 전쟁과 평화 = **치열한 현재 → 안정된 미래**. 문 = 통과의 관문(치열한 입시를 지나 더 큰 세상으로).
- **태그라인:** "미래를 여는 문" / "과거를 통찰하고, 미래를 응시하다" / "치열한 현재에서 안정된 미래로".
- **로고(확정 방향):** 좌우 대칭 **아치문**. 왼쪽 **네이비**(과거·치열한 현재) / 오른쪽 **골드**(미래·안정된 미래) / 상단에 **두 개의 흰 점(두 얼굴, 눈동자 없음)** / 상단 은빛 이맛돌·하단 은빛 받침. (분할 게이트=중앙이 뚫려 빛나는 안, 응시안=두 눈 등 변형 존재)
- **컬러:** 네이비 `#24405f` · 골드 `#cf9a3a` · 블루 `#2f6fb3` · 실버 `#c7ccd2`.
- **로고 마감:** 원본성 프리미엄 마감은 클로드 디자인에 위임(프롬프트·기준 이미지 준비됨).

## 3. 데이터 & 방법론 (핵심)

### 3-1. 고속성장분석기 작동원리(중요)
- 사용자 입력 = **표준점수**(국·수·탐), 등급(영·한). "백분위 입력 불가".
- 표점 → 백분위·누적% 환산(SUBJECT1 시트: 실채점 인원 분포). → **이과/문과 계열별 전국 누백** 재계산.
- 대학별 환산점수 계산(COMPUTE) → 누적백분위별 환산점수표(PERCENTAGE, 0.01%간격) → 적정80/예상50/소신20 판정.
- 우리가 추출: **표점합/백분위합 → 전국누백 역보간표**(`고속_표점_누백_환산.json`, 계열별). 이과 표점합 예: 국147+수139+탐74+탐71=431.

### 3-2. 데이터 원천
- **어디가 2026 정시 실측:** 187개교 재수집(`adiga_정시_2026결과_전국187_2026-06-26.json`, 12,491행, ajax `criteriaAndResultItemNewAjax.do` searchSyr=2027). ⚠기존 파일은 사실 2025결과였음(보존).
- **esteacher 3개년 실측:** `esteacher_정시_입결_3개년_2024-2026_2026-06-29.json`(단일 정적 JSON, 5,770 모집단위, 어디가 실측과 94% 일치).
- **고속 다년:** `seed/고속_다년_입결_2111_2511_INTERNAL.json`(2022~2024=백분위·2021/2025=환산, 내부검증 한정).
- **수시(전국) esteacher:** 정적 JSON `admission-data.json`(16,129행, 약 26% 비실측→필터).

### 3-3. 보정
- 고속 예상누백 ↔ 어디가 실측백분위 **Spearman ρ=−0.87**. 누백→백분위 계열별 보정곡선(이과/문과) → **MAE 6.75→4.96**(계열보정). 다년 통합(bEst 앵커=다년평균 우선).

### 3-4. 백테스트 결과(작년으로 올해를 예측했다면)
- 컷 예측오차(평균백분위): 70%컷 단년 MAE 11.1 → **2년평균 8.4**(다년 앵커 타당). 
- **점수대 이극화:** 백분위 90~95 MAE 2.9 / 80~90 4.8 / 70~80 8.6 / 50~70 14.4 / <50 27.0(예측한계).
- **합격확률 백테스트:** 작년 50%컷 타깃 → 올해 실제 합격확률 ≈ **48.7%**, 작년 70%컷 → **37%**. → "작년 70%컷=안정"은 오해, 한 단계 상향 필요.
- 라인별 오차: 서성한/중경외시/건동홍/인가아 ±2.6~3, 지거국 ±8.7.
- 고속 단년 정확도: 어디가 실측 대비 ±5점 수준(계열보정 시 MAE 4.96).
