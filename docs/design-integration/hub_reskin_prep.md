# 배치표 허브 리스킨 준비 — janus_report_hub_v1 기준

> 목표: 현재 `PlacementHubPage`를 시안(`janus_report_hub_v1_reference.html`)에 맞춰 리스킨.
> 결론: **컬러 토큰은 이미 일치** — 남은 건 구조(탭 편입·포트폴리오)·탭 스타일·배경 미세값. 아래는 실행 체크리스트.
> 최종 정리: 2026-07-15.

## 1. 토큰 대조 (이미 일치 ✅)

| 용도 | 시안 값 | 현재 토큰 | 상태 |
|---|---|---|---|
| 메인 블루 | `#2f6fb3` | `--j-blue #2f6fb3` | ✅ 동일 |
| 블루 soft | `rgba(47,111,179,.1)` | `--j-blue-soft` | ✅ 동일 |
| 잉크(타이틀) | `#1e3550` | `--j-ink #1e3550` | ✅ 동일 |
| 네이비/보조 | `#24405f` | `--j-navy #24405f` | ✅ 동일 |

→ **리스킨 시 색·폰트 변경 불필요.** 배경만 허브 한정 `#f4f6fa`로 맞출지 결정.
→ **결론: 시각 토큰 완전 정렬. 리스킨 = 순수 구조 작업**(격차 탭 편입 + 포트폴리오 탭 N28 + 탭 스타일 택1).

## 2. 구조 차이 (실제 작업)

| 시안 요소 | 현재 | 작업 |
|---|---|---|
| GNB·타이틀·탭 고정 + iframe 스왑 + 프리로드 + 0초 전환 | ✅ 구현됨 | 유지 |
| 탭: 격차 리포트 / 정밀배치표 / **지원 포트폴리오** / 수시 입결 / 카이로스 | manifest 기반(포트폴리오 없음) | ↓ |
| **격차 리포트가 허브 탭** (신호등 요약 + "격차를 좁히는 다음 문") | 별도 `/placement/gap` 페이지 | **허브 탭으로 편입** — gap 콘텐츠를 탭 패널로 |
| **지원 포트폴리오(◫)** 탭 | 없음 | **신규** — N28(가·나·다 조합) 확정 후 |
| 탭 스타일 | pill(둥근 알약) | 시안=underline(하단 2.5px `#2f6fb3`) — 택1 |
| 브레드크럼 홈›배치표›{탭} | 유사 구현됨 | 구분자색 `#c2ccd8` 정렬 |
| 서브타이틀(이과·컴퓨터공학·2027 입시) | 없음 | 계열·목표학과 컨텍스트 표기 |
| 데이터 버전 배지(병합 v8·갱신일) | `updated`만 | 병합 버전 노출(실데이터 후) |

## 3. 실행 순서(제안)

1. **탭 스타일 결정** — pill 유지 vs 시안 underline. (시각만, 30분)
2. **격차 탭 편입** — `GapReportPage`를 허브 탭 패널로 렌더(현재 embedded 라우트와 병행). 서브타이틀·신호등 요약 블록 추가.
3. **배경/브레드크럼 미세 정렬** — `#f4f6fa`, 구분자색.
4. **지원 포트폴리오 탭** — N28 확정 후 신규 (별도 작업).

## 4. 주의(C6)

- 시안 파일·이 문서에 저작권 배치표 데이터 없음(표는 `/jeongsi`·`/susi`·`/kairos` iframe = 엔진/JANUS_DATA_DIR).
- 리스킨은 **액자(chrome)** 만 — 표 내용은 엔진 산출물, 손대지 않음.
- 실데이터 확보(다른 노트북) 전까지 데모 허브로 검증.
