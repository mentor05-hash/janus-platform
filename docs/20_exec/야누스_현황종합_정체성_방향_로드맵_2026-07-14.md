## 1. 야누스의 정체성 (무엇인가)

### 1-1. 한 문장 정의
> **야누스는 "치열한 현재"의 데이터를 읽어 "안정된 미래"로 가는 문을 여는 전환(轉換) 관문 플랫폼이다.**
> 본질 루프: **진단(지금 어디인가) → 처방(무엇을 하면 되는가) → 실행(누구와·어떤 도구로) → 통과(문을 지남) → 다음 관문.**

야누스가 파는 것은 개별 기능이 아니라 **"최적화된 솔루션 + 그것을 실제로 수행하게 하는 도구"의 묶음**이다. 자체 개발 기능과 외부 툴을 어댑터·SSO·파트너 허브로 통합하고, **서비스를 받으려는 쪽(학생·학부모)과 제공하려는 쪽(선생님·컨설턴트·학원·교육기업)을 하나의 계정·데이터 규약 위에** 올린다.

### 1-2. 경쟁 명제 (해자)
> 경쟁자는 "도구"나 "매칭" 중 **하나만** 판다. 야누스는 **진단 데이터가 실행 서비스를 부르고, 실행 결과가 다시 진단 데이터를 좋게 만드는 폐쇄 루프**를 가진 유일한 플랫폼이 된다.

두 자산의 상보성이 통합의 근거다:
- **실행 인프라(구 잇올 멘토링)**: 매칭·예약·실시간수업·강의·컨설팅·정산까지 프로덕션급 완성. 약점 = "왜 상담을 받아야 하나"의 **동기(진단) 부재**.
- **진단 엔진(야누스 데이터 도구)**: 배치표·입결·합격예측(계열보정 MAE 4.96, 다년 앵커). 약점 = 진단 후 "그래서 뭘 하지"의 **실행 경로 부재**.

→ **A의 파이프에 B의 물을 흘리는 것**이 통합의 전부. B(배치표)=최고의 획득 장치, A=최고의 수익화 장치.

### 1-3. 잠금(lock-in) 구조
- **데이터 귀속**: 성적(janus_score)·목표(janus_goal)·진단(janus_report)·정산 이력이 야누스 계정에 누적. 성적 1회 입력이 전 서비스에 연동.
- **추천 관문 독점**: 진입 트래픽이 관문 홈의 커리큘럼 추천을 통해 배분됨.

### 1-4. 브랜드 경계 (준수 사항)
야누스=독립 브랜드. 산출물·코드·문서에 **잇올/janus 명칭 노출 금지**(이번 세션까지 레거시·메일·랜딩에서 제거 완료). 단, 내부 식별자(`com.example.mentoring`·`COMPOSE_PROJECT_NAME=janus-platform`·DB user `janus`)는 빌드·볼륨 호환을 위해 유지 — 스토어 재등록·인프라 이전 시점에 별도 정리(O47, 백로그).

## 4. 현재 사업방향 (어디로 가는가)

### 4-1. 두 개의 획득 깔때기
1. **대입(고2~N수)**: 배치표가 부른다. 성적표 사진 1장(OCR) 또는 관문 홈 한 줄 질문 → 무료 배치표+격차 리포트 → 커리큘럼 카드 → 상담(크레딧) → 컨설팅(원화)/강의(좌석) → 성적 재입력(리텐션).
2. **레벨 미스매치(중·고 전학년+보호자, 신규 웨지)**: 학년제 학원·인강이 **구조적으로 못 푸는 공급 공백**. 수준 진단 → 예산·기간 입력 → 온·오프 조합 학습설계 → 페이싱 가드(과속 실패 차단). 입구를 2배로 넓힌다.

### 4-2. 단가 사다리 (경제 설계)
> **무료(배치표·간이진단) → 크레딧(상담·과외) → 원화(클리닉·VOD·컨설팅) → 좌석(라이브)**

- 무료 티어는 **절대 훼손 금지**(획득 장치).
- VOD는 한계비용 0 상품 — "강사는 한 번 가르치고 두 번 판다(라이브 좌석 + VOD 수강권)". 대형 인강 비경유가 강사 유인이자 콘텐츠 원가 0 수렴 구조.
- 클리닉(1:3~8)이 과외(고단가)와 라이브(저단가) 사이를 메워 사다리를 촘촘히.

### 4-3. 심장 지표
> **전환율이 이 사업의 심장.** 관리: 성적입력→배치표 사용률 · **배치표→상담 전환율(핵심)** · 상담→컨설팅/강의 전환율 · 회원→유료 전환율 · 재입력(리텐션)율 · 크레딧 소멸률(마진).

### 4-4. 수익원 (B2C/B2B/제휴)
- B2C 진단(티어 구독)·실행(상담·컨설팅)·학습(과외·클리닉·라이브·VOD·수준진단)
- B2B SaaS(센터 운영)·API(화이트라벨 룸 ✅부하실측 / 배치표 API ⚠데이터 권리 선행)
- 제휴 파트너 허브(인강·모의고사·자소서·플래너 — 입점·전환 수수료)

- **미완의 핵심은 전부 코드 밖**: LiveKit·Cloudflare·법률·PG·가격.
- **시즌 앵커**: 9월 모평(초)·수시 원서(중순) = W9~W10 트래픽 기회. **역산하면 무료 배치표 소프트 런칭 마지노선 = 8월 중(W6).** 이 데드라인이 모든 우선순위를 지배한다.

### 6-1. 즉시(이번 주~다음 주, W2 잔여) — "런칭 파이프라인 개통"
| 순위 | 항목 | 유형 | 완료 기준 |
|---|---|---|---|
| 1 | **데이터 권리 법적 검토 착수** | [BIZ] | 변호사 상담 예약 또는 대교협 문의 초안 발송. **W6 소프트 런칭의 게이트 — 리드타임이 길어 가장 먼저 시작** |
| 2 | **4단계 티어 빌드 파이프라인(무료판 우선)** | [CC] | `dist-tier/free`에 원본 컷·표본 데이터 물리적 부재 grep 증빙 + 워터마크·면책 고지·간이 로그 |
| 3 | **LiveKit Cloud 개통** | [EXT] | ENV 4종 투입 → 실기기 2대 통화 + 녹화 파일 생성 확인(강의실 음성·VOD 라인 활성) |
| 4 | **Cloudflare 도메인·R2·Tunnel·Pages** | [EXT/OPS] | 외부망 도메인 접속 성공 + 맥 중지 상태에서도 무료 배치표 열림(정적/동적 분리) |
| 5 | **가격 미결 3건 초안→확정** | [DEC] | N23 유료가·N24 무료 노출 수·N25 게이트 방식 → Decision-Register 기록(티어 빌드에 선행) |

### 6-2. 이번 달(W3~W4) — "계정으로 묶기 + Phase 0 출구"
- 회원 티어 빌드 + SSO 게이트 연결 → 로그인→배치표 회원판 자동 인증 E2E.
- **격차 리포트 v1**(janus_report 스키마 첫 구현): 배치표 결과 → "목표까지 누백 X 부족 + 작년 70%컷=합격률 37% 근거 + 처방 CTA".
- **Phase 0 출구 게이트(반드시 통과)**: **성적 1회 입력(OCR) → 배치표 자동 반영 → 격차 리포트 → 커리큘럼 카드 → 상담 예약**을 한 계정으로 끊김 없이 통과. + 무료판 법적 점검표 이상 없음.

### 6-3. 8월(W5~W8) — "Q&A 트랙 + 소프트 런칭 + 학습 상품"
- **W6 무료 배치표 소프트 런칭**(법률 게이트 통과 조건부) — 전환 관측 시작.
- Q&A 순차: Q1(SLA·소프트블록) → Q2(스코프 3종·재답변 한도) → Q3(3부 공개 게시판+AI 초안=커뮤니티 v1) → Q4(리그 승급·크레딧).
- 수준 진단 v1(진단 상담 상품+janus_report) · 과외·클리닉 파일럿(레벨 미스매치 5~10명).
- 학부모 주간 통합 리포트 v1.

### 6-4. 9월(W9~W12) — "결제 개통 + 시즌 + Phase 1 출구"
- **사업자등록·통신판매업 신고**(PG 선행 필수) → **토스페이먼츠 실연동 + 환불 v1** → 크레딧 충전 정식화.
- 유료 티어 빌드 + SSO 게이트. 컨설팅 LLM에 배치표 근거 필드(접합 #4).
- **W9~10 신규 개발 금지 — 운영·관측만**(시즌 트래픽).
- **Phase 1 게이트**: ①배치표→상담 전환율 실측 ②유료 결제 첫 사이클 완주 ③파일럿 재진단 성취 1건+ ④Q&A 리그 가동.

### 6-5. Phase 2~4 (지도 — 트리거 시 개시)
- **Phase 2(3~6개월)**: 라이브 SKU 확정·**VOD 상품화(플레이어·수강권)**·예산 최적화 학습설계 엔진·지식맵 v1·수시 라인 통합.
- **Phase 3(6~12개월)**: B2B API 상품화·파트너 허브 실입점·공급자 셀프서브·VOD 마켓플레이스.
- **Phase 4(12개월~)**: 2028 대입 개편 대응·다음 관문 수평 복제(편입·유학·취업·심리 코칭)·자체 예측 모델(저작권 리스크 근본 해결).

## 9. 확장 청사진 요약 (지금 안 해도 되는 것 — 트리거 대기)

새 버티컬 = 진단+공급자+규제 3비용으로만 평가. 후보 채점:
- ① **수험생 멘탈 코칭** — 최우선(입시×심리 교집합, 의도분류에 이미 존재). 3단 구조(L1 셀프케어→L2 코칭→L3 임상)로 안전 분리, LLM은 심리 판정 금지.
- ② 편입·유학·취업(커리어) — 대입 통과 고객의 자연 연장, Year 2 본명.
- ③ 자기개발·습관·어학·자격 — 규제 최저·재사용 최고, 코칭과 묶어 진입.
- ④ 임상 심리상담 — 규제 최고, Year 2~3 요건 완비 후.
- ⑤ 성인 재교육 — B2B 결합 시 강함, 글로벌 시너지.

**모두 트리거 조건 충족 시에만 개시. 현재 유일한 활성 계획은 12주 실행계획서다.**
