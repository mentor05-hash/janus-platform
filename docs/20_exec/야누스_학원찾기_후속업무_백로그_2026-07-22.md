## 2. 실 어댑터 연동 대기 (외부 키·계약)

> 코드는 어댑터 뒤 stub 로 준비 완료. 키/계약 확보 후 `*_PROVIDER=real` 로 전환하면 동작.

| 어댑터 | 현재(stub) | 실연동 착수점 |
|---|---|---|
| **본인확인**(학부모 동의 ① · 학원 클레임) | `IdentityVerifyProvider` — 형식검증만, 마스킹 참조 저장 | `identity-verify.provider.ts` `mode()==='real'` 분기에 PASS/NICE/KMC SDK 호출. ENV `IDENTITY_VERIFY_PROVIDER=real` |
| **dong 역지오코딩**(정류장 좌표→행정동) | `DongResolver` — 명시 dong_code 만, 좌표는 지어내지 않음 | `dong-resolver.ts` `mode()==='real'` 분기에 행정경계 GIS/공공 API. ENV `DONG_GEOCODER=real` |
| **공공데이터 sync**(교육청 학원 원장) | `PublicSyncService.syncFromDataDir` — 경로만 준비 | ⑮ 통과 후 `JANUS_DATA_DIR/academies/` 실데이터 + 월 배치 스케줄(@Cron) |

## 3. 미착수 기능(스펙 범위 밖 — 백로그)

- **리드 직접 통지 채널**(학원↔학생 알림톡/이메일): 현재 인박스 왕복(계정 내)만. 실채널은 ⑯·인프라 후.
- **학원 상세 지도 뷰 / 기기측 반경 매칭**(㉒).
- **관리자 대시보드에 검색→리드 전환율 카드 노출**: `funnel.summary.academy` 지표는 산출 완료 — AdminStats/대시보드 화면에 붙이기만 하면 됨.
- **학원찾기 검색 지표의 센터 격리**: 현재 전역. 필요 시 INV-11(센터 격리) 패턴 적용.

## 4. 재개 방법

- 정책 확정분: 위 표의 "착수점" 파일 열어 해당 분기/값 교체 → 실측 → 커밋.
- 실데이터: `JANUS_DATA_DIR`(ENV, repo 무반입) 경로에 배치 후 `POST /admin/academies/sync`.
- 전체 세션 코드는 `apps/api/src/modules/academy-finder/`(백엔드) · `apps/web/src/pages/Academy*.tsx` · `apps/mobile/src/screens/AcademyFinderScreen.tsx`.
