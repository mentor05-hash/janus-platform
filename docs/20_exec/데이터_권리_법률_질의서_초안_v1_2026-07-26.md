## 1. 사업 개요 (사실관계)

- 서비스: 대입·입시 준비 학생을 대상으로 **진단 → 처방 → 실행**을 연결하는 온라인 플랫폼(가칭 야누스). 운영 주체는 1인 사업자 준비 단계.
- 문의 대상 기능: **대학 배치표·입시 결과(입결)·경쟁률 등 입시 통계를 가공해 "지원 가능성 구간(안정/적정/소신/상향)"을 제시하는 기능.**
- 데이터 성격(종류 수준으로 기술):
  1. 대학·학과별 과거 입시 결과 통계(합격선·백분위·경쟁률 등)
  2. 모의고사·수능 성적 환산 기준
  3. 이용자가 직접 입력한 본인 성적(서버 미저장 설계 검토 중)
- 취득 경로: `[A 빈칸]`
- 가공 방식: 원본 수치를 그대로 노출하지 않고 **자체 산식으로 구간·확률·신뢰도 등급을 산출**해 표시. 원본 컷은 유료·컨설턴트 등급에서만 취급 예정.
- 공개 계획: **무료 등급**은 구간별 대표 항목 소수만 색상·구간으로 표시(수치 마스킹), 상세·검색은 회원 이상. 규모 `[D 빈칸]`.

## 2. 질의 사항

각 항목에 **예/아니오 또는 조건**으로 답을 받을 수 있게 구체화했다.

### 2-1. 가공물 공개의 적법 범위
1. 위 §1 방식(원본 수치 비노출 + 자체 산식 가공)으로 만든 **가공 결과물을 무료 공개**하는 것이 원 데이터에 대한 권리를 침해하는가?
2. 침해가 아니라면, 그 판단의 근거는 무엇인가(아이디어·사실 자체의 비보호 / 창작성 없는 데이터 / 인용 등)? 판단이 달라지는 **경계 조건**은 무엇인가?
3. **데이터베이스제작자의 권리**(저작권법 제91조 이하) 관점에서, "상당한 투자로 제작된 데이터베이스의 상당 부분 복제·전송"에 해당할 위험이 있는가? 우리가 노출 개수를 줄이면 위험이 실질적으로 줄어드는가, 아니면 개수와 무관한가?

### 2-2. 무료 공개 vs 유료 판매
4. **무료 공개**와 **유료 판매**에서 법적 평가가 달라지는가? 달라진다면 어느 지점에서 달라지는가(영리성·경쟁 대체성 등)?
5. 무료 등급을 유료 전환 유인으로 쓰는 구조(무료는 일부만, 상세는 유료)가 평가에 영향을 주는가?

### 2-3. 출처 표기·면책의 효력
6. **출처 표기**와 **예측 면책 고지**로 해소되는 위험은 무엇이고, **해소되지 않는** 위험은 무엇인가?
7. 면책 고지 문구에 반드시 포함해야 하는 요소가 있는가(예측의 한계·기준 시점·책임 귀속 등)?
8. 이용자가 결과를 신뢰해 지원했다가 불합격한 경우, 예측 제공자의 책임 범위는 어떻게 보아야 하는가? 약관으로 제한 가능한 범위는?

### 2-4. 자체 수집·이용자 입력 데이터
9. 이용자가 직접 입력한 성적을 **통계로 집계해 자체 데이터로 축적·활용**하는 것이 가능한가? 필요한 동의의 형태는?
10. 그렇게 축적한 자체 데이터로 만든 예측을 **유료 판매**하거나 **B2B 제공**할 때 추가 제약이 있는가?

### 2-5. 미성년 개인정보
11. 주 이용자가 **미성년(중·고등학생)**이다. 성적·생활기록부 등을 업로드받아 상담에 활용할 때 요구되는 절차는 무엇인가(법정대리인 동의 요건·연령 기준·동의 방법)?
12. 생활기록부에 포함된 제3자 정보(교사 평가 등)를 처리할 때 추가 고려사항이 있는가?
13. 보관기간·파기 의무의 기준은? 상담 종료 후 어느 시점까지 보관 가능한가?

### 2-6. B2B·재판매
14. 가공 결과물을 **API·화이트라벨로 학원·교육기업에 제공**할 때, §2-1 판단이 달라지는가?
15. 재판매 시 원 데이터 제공자와 별도 라이선스가 필요한가? 필요하다면 통상 어떤 형태인가?

### 2-7. 승계 코드·자산
16. 기존에 운영하던 별개 서비스의 코드베이스를 이 사업에 승계해 쓰고 있다. 지분·계약 관계가 정리되지 않은 상태에서 **외부 공개·매출 발생** 전에 정리해 두어야 할 서면은 무엇인가?

## 3. 우리 쪽 가정과 대안 (검토 편의)

| 가정 | 대안(가정이 틀릴 경우) |
|---|---|
| 원본 수치를 노출하지 않고 구간·등급만 보이면 위험이 낮다 | 노출 개수를 더 줄이거나, 자체 수집 데이터 비중이 확보될 때까지 공개를 연기 |
| 출처 표기 + 면책 고지로 상당 부분 해소된다 | 데이터 제공자와 정식 라이선스 협의(비용 발생 감수) |
| 이용자 입력 성적은 서버에 저장하지 않으면 개인정보 이슈가 작다 | 저장이 필요해지면 별도 동의·암호화·보관기간 정책 수립 |
| 무료 공개는 유료 판매보다 위험이 낮다 | 무료도 동일 기준이면 전면 재설계(자체 데이터 기반으로 전환) |
