## 3. 작업 규약 — 어기면 바로 물린다

**판정은 원격에서 한다.** `git remote -v` 는 아직 `mentor05-hash` 를 가리킨다(GitHub 리다이렉트로 동작). 소유자·PR·브랜치는 `gh` / `git ls-remote` 로 확인한다.

**CI 판정은 check-runs 로 한다.** 이 저장소는 legacy commit status 를 쓰지 않아 `get_status` 는 빈 결과를 준다.

**required 검사 이름의 가운뎃점은 U+00B7 이다.** 손으로 타이핑하지 말고 라이브 설정에서 복사한다. 현재 7개:

```
E2E (postgres)
Lint · Build · Unit
Web (typecheck · unit)
Mobile (typecheck · expo export)
Smoke E2E (ops curl 스크립트)
머지 준비 확인 (미완성 표식)
이미지 빌드 (web · api · mobile · rooms)
```

**`strict: true` 다.** base 가 움직이면 PR 이 `BEHIND` 로 막힌다 → `gh pr update-branch <번호>`.

**커밋에 gitleaks 가 필요하다.** 미설치면 fail-closed 로 커밋 자체가 차단된다(이 기기엔 8.30.1 설치됨). 훅 연결은 `git config core.hooksPath .githooks` — 클론에 따라오지 않는다.

**lock 을 건드릴 때 주의.** `npm install --package-lock-only` 가 `@esbuild/*` 크로스플랫폼 바이너리를 **23개 → 1개**로 쳐낸다(macOS 는 linux 를, 컨테이너는 darwin 을 버린다). 그대로 커밋하면 우분투 CI 가 깨진다. 필요하면 컨테이너에서 전체 재생성 + 별도 검증.

**Docker 는 워크스페이스를 쪼갠다.** 호스트 `npm ci` 는 모든 워크스페이스를 한 트리에 설치하므로 **선언하지 않은 것에 호이스팅으로 얹혀 있어도** 통과한다. 이미지 빌드에서만 드러난다 — 새 패키지를 만들면 **Dockerfile 의 워크스페이스 COPY 목록에 반드시 추가**할 것(O200).

**계층별 검증**: `apps/api` 수정 → `npm run format:check` · `packages/nav` 수정 → `apps/web` vitest(래칫 31/20/8 + 모바일 드리프트 15건).

## 4. 열린 일 — 우선순위 순

### ① 도메인 구입 (가장 급함 — 8월 런칭 직결)

W1 D2 와 **W2 D3**(Cloudflare Tunnel 로 `api.<도메인>`·`rooms.<도메인>`) · **W2 D4**(`janus-public` → Pages 커스텀 도메인)가 전부 여기 막혀 있다. 무료 배치표의 공개 주소도 마찬가지다.

- `janus-corp.com` 은 **이미 타인 보유**(NS GoDaddy). `janus-corp` 은 GitHub 조직 이름이지 도메인이 아니다.
- `.com` 은 Cloudflare Registrar 가 원가 판매(마진 0) — 계정이 이미 있어 DNS·Pages·Tunnel 연결이 바로 된다.
- `.kr` 은 Cloudflare 에서 못 산다(국내 등록기관 → NS 만 Cloudflare 로). `.co.kr` 은 **사업자등록 필요**.

### ② W2 D2 무료판 마감 — 선행 2건이 남았다

요구 5개 중 워터마크+면책·간이 접속로그는 W2 D1 이 주입식으로 이미 처리한다. 나머지 셋(4구간 노출·수치 마스킹·입력 제한)은 플래그 **선언만** 있고 동작하지 않는다:

- **마스터에 센티넬 태깅 + `__JANUS_FLAGS` 읽는 JS** — 실제 마스터 14개 전부 훅 0건. **배치표 독립 트랙 몫**.
- **N24(무료 노출 학과수) 확정** — 미착수, W3 예정. `tiers.config.json` 의 `recPerBand: 4` 는 임시값이며 가격 미결 3건과 묶인 본부 결정이다.

배포 게이트(`tier_verify`)는 O201 로 정직해졌지만, 그것이 D2 를 진행시키지는 않는다.

### ③ 외장 디스크 — 3-2-1 의 '매체 2종'

`tmutil destinationinfo` 가 `No destinations configured`. **R2 는 랜섬웨어·자격증명 침해를 막지 못한다**(저장소를 지울 토큰이 백업 대상 기기 안에 평문으로 있다). 이유와 운용 규약은 백업 운용 런북 §2~§3.

### ④ 잔여 확인 2건

- **`RESTIC_PASSWORD` 사본이 실제로 열리는지 미검증.** 관리자에 보관은 했으나(2026-07-31), 그 값으로 `restic snapshots` 를 한 번 열어 봐야 확인이다. 잘못 옮겨 적은 암호는 없는 것보다 나쁘다.
- **조직 rulesets 는 0건**으로 확인됐다(2026-07-31). 재확인이 필요하면 `repos/{owner}/{repo}/rulesets?includes_parents=true` 로 충분하고, `admin:org` 스코프를 열 필요가 없다.

## 5. 이번 세션에서 드러난 패턴

**"CI 초록"이 "동작한다"를 뜻하지 않는 경우가 반복해서 나왔다.**

| 겉보기 | 실제 |
|---|---|
| 브랜치 보호 규칙 존재 | 개인 Free 플랜에선 발효되지 않음 — 판정은 GraphQL `isRequired` |
| gitleaks 훅이 돌고 통과 | 차단 경로는 미실측이었음(가짜 키 시험 필요) |
| CI 7잡 전부 초록 | web·api·mobile 이미지가 **하나도 빌드되지 않음** |
| 무료판 게이트 "공개 배포 가능" | 저작권 데이터가 든 4.7MB 원본이 그대로 통과 |

**검증 자체가 대상을 빗나갈 수 있다.** 이미지 CI 잡을 넣으며 "로컬에서 모바일 이미지 빌드 통과"라고 확인했는데, `docker compose build` 로 한 것이라 **잡이 쓰는 경로는 한 번도 실행되지 않았다**(실제 파일은 `Dockerfile.web`). 새로 만든 잡이 첫 실행에서 그 오류를 스스로 잡았다.

교훈은 하나다 — **"완료 = 실측"에서 '무엇을' 실측했는지까지 확인해야 한다.**
