## 3. 작업 규약 — 어기면 바로 물린다

**판정은 원격에서 한다.** `git remote -v` 는 아직 `mentor05-hash` 를 가리킨다(GitHub 리다이렉트로 동작).
소유자·PR·브랜치는 `gh` / `git ls-remote` 로 확인한다. **remote URL 은 근거가 아니다.**

**CI 판정은 check-runs 로 한다.** 이 저장소는 legacy commit status 를 쓰지 않아 `get_status` 는 빈 결과를 준다.
`gh pr checks <번호> --watch` 가 가장 확실하다.

**required 검사 이름의 가운뎃점은 U+00B7 이다.** 손으로 타이핑하지 말고 라이브 설정에서 복사한다. 현재 7개:

```
머지 준비 확인 (미완성 표식)
E2E (postgres)
Lint · Build · Unit
Mobile (typecheck · expo export)
Smoke E2E (ops curl 스크립트)
Web (typecheck · unit)
이미지 빌드 (web · api · mobile · rooms)
```

**`strict: true` 다.** base 가 움직이면 PR 이 `BEHIND` 로 막힌다 → `gh pr update-branch <번호>`(검사 재실행됨).
**승인 요구는 0** 이라 1인 체제에서 교착은 없다. `enforce_admins: true` 라 우회도 없다 — 7잡 전부 초록이어야 머지된다.

**커밋에 gitleaks 가 필요하다.** 미설치면 fail-closed 로 커밋 자체가 차단된다(이 기기엔 8.30.1).
훅 연결은 `bash scripts/setup-hooks.sh` — **클론에 따라오지 않고 조용히 풀린다**(§0·§5).

**한글 파일명은 git 에서 위양성 "없음"을 만든다.** git 은 non-ASCII 경로를 8진 이스케이프로 따옴표까지
붙여 출력하므로 `ls-tree | grep "한글"` 이 **매치 0건**을 준다 — 파일이 실제로 있어도. 이 문서를 찾을 때
실제로 "전 브랜치·전 히스토리에 없음"이라고 오판했었다.

- 읽기: `git -c core.quotePath=false show <ref>:<경로>`
- 경로 순회: `while IFS= read -r p` (셸 변수로 넘기면 따옴표째 들어간다)
- 머지 커밋: `git show <merge> -- <경로>` 는 빈 결과 → `<merge>^2` 또는 `<merge>:<경로>`

(CLAUDE.md §5 "한글 파일 패치는 python replace/heredoc" 규칙의 git 판본.)

**lock 을 건드릴 때 주의.** `npm install --package-lock-only` 가 `@esbuild/*` 크로스플랫폼 바이너리를
**23개 → 1개**로 쳐낸다(macOS 는 linux 를, 컨테이너는 darwin 을 버린다). 그대로 커밋하면 우분투 CI 가 깨진다.
필요하면 컨테이너에서 전체 재생성 + 별도 검증.

**Docker 는 워크스페이스를 쪼갠다.** 호스트 `npm ci` 는 모든 워크스페이스를 한 트리에 설치하므로
**선언하지 않은 것에 호이스팅으로 얹혀 있어도** 통과한다. 이미지 빌드에서만 드러난다 —
새 패키지를 만들면 **Dockerfile 의 워크스페이스 COPY 목록에 반드시 추가**할 것(O200).

**계층별 검증**: `apps/api` 수정 → `npm run format:check` · `packages/nav` 수정 → `apps/web` vitest
(래칫 31/20/8 + 모바일 드리프트 15건).

## 4. 열린 일 — 우선순위 순

### ① 도메인 구입 (가장 급함 — 8월 런칭 직결)

W1 D2 와 **W2 D3**(Cloudflare Tunnel 로 `api.<도메인>`·`rooms.<도메인>`) · **W2 D4**(`janus-public` → Pages
커스텀 도메인)가 전부 여기 막혀 있다. 무료 배치표의 공개 주소도 마찬가지다.

- `janus-corp.com` 은 **이미 타인 보유**(NS GoDaddy). `janus-corp` 은 GitHub 조직 이름이지 도메인이 아니다.
- `.com` 은 Cloudflare Registrar 가 원가 판매(마진 0) — 계정이 이미 있어 DNS·Pages·Tunnel 연결이 바로 된다.
- `.kr` 은 Cloudflare 에서 못 산다(국내 등록기관 → NS 만 Cloudflare 로). `.co.kr` 은 **사업자등록 필요**.

**이름 확정은 본부 결정이다** — 밖에서 정하지 않는다. 이게 나오기 전엔 W2 D3·D4 를 진행할 수 없다.

### ② W2 D2 무료판 마감 — 선행 2건이 남았다

요구 5개 중 워터마크+면책·간이 접속로그는 W2 D1 이 주입식으로 이미 처리한다.
나머지 셋(4구간 노출·수치 마스킹·입력 제한)은 플래그 **선언만** 있고 동작하지 않는다:

- **마스터에 센티넬 태깅 + `__JANUS_FLAGS` 읽는 JS** — 실제 마스터 14개 전부 훅 0건. **배치표 독립 트랙 몫**.
- **N24(무료 노출 학과수) 확정** — 미착수, W3 예정. `tiers.config.json` 의 `recPerBand: 4` 는 임시값이며
  가격 미결 3건과 묶인 **본부 결정**이다.

배포 게이트(`tier_verify`)는 O201 로 정직해졌지만, 그것이 D2 를 진행시키지는 않는다.

### ③ 외장 디스크 — W1 D5 의 마지막 미충족

`tmutil destinationinfo` 가 여전히 `No destinations configured`.
**R2 는 랜섬웨어·자격증명 침해를 막지 못한다** — 저장소를 지울 토큰이 백업 대상 기기 안에 평문으로 있고
(`~/.config/janus/backup.env`), restic 은 S3 백엔드에서 append-only 를 지원하지 않는다.
이유와 운용 규약(상시 연결은 방어가 아니다 — 뽑아 둔 시간에서 가치가 나온다)은 백업 운용 런북 §2~§3.

**W1 D5 는 이제 이것 하나만 남았다** — 오프사이트·복원 리허설·암호 사본 검증은 전부 닫혔다.
외장이 붙으면 항목을 닫을 수 있다. 물리 장비 건이라 코드로 진행할 수 없다.

## 5. 반복해서 드러나는 패턴 — 다음 세션도 이걸 밟는다

**"체크돼 있다"가 "지금 동작한다"를 뜻하지 않는 경우가 계속 나온다.**

| 겉보기 | 실제 |
|---|---|
| 브랜치 보호 규칙 존재 | 개인 Free 플랜에선 발효되지 않음 — 판정은 GraphQL `isRequired` (O198) |
| CI 7잡 전부 초록 | web·api·mobile 이미지가 **하나도 빌드되지 않음** (O200) |
| 무료판 게이트 "공개 배포 가능" | 저작권 데이터가 든 4.7MB 원본이 그대로 통과 (O201) |
| W1 D1 "gitleaks 차단 3종 실측 완료" 체크됨 | **훅이 배선조차 안 돼 있었다** — 실측은 진짜였으나 유지되지 않았다 (O202) |
| `RESTIC_PASSWORD` 사본을 관리자에 보관함 | 그 값으로 저장소를 **한 번도 열어 보지 않았다** — 보관은 검증이 아니다 (O202) |

**검증 자체가 대상을 빗나갈 수 있다.** 이미지 CI 잡을 넣으며 "로컬에서 모바일 이미지 빌드 통과"라고
확인했는데 `docker compose build` 로 한 것이라 **잡이 쓰는 경로는 한 번도 실행되지 않았다**.
같은 함정이 암호 검증에도 있었다 — `backup.env` 의 값으로 `restic snapshots` 를 돌리면 *원본*을 확인한
것이지 *사본*을 확인한 것이 아니다(그래서 스크립트가 그 값을 `unset` 한다).

**대조군 없는 통과는 통과가 아니다.** 차단 시험 3종이 전부 "차단됨"이어도, 훅이 **전부** 막는 고장 상태면
똑같이 3종 통과다. 시크릿 없는 커밋이 **정상 통과**하는 것까지 봐야 "선별적으로 막는다"가 성립한다.
합격 조건도 종료코드만 보면 안 된다 — **exit≠0 + HEAD 불변** 둘 다 봐야 "떠들었지만 커밋은 됐다"를 걸러낸다.

교훈 셋:

1. **"완료 = 실측"에서 '무엇을' 실측했는지까지 확인한다.**
2. **체크박스는 "그때 됐다"만 말한다** — 지금도 그런지는 별도로 봐야 하고, 그래서 §0 과 주간 점검이 있다.
3. **판별력을 먼저 검증한다** — 시험이 실패를 실제로 잡아내는지(음성 대조) 확인하지 않은 통과는 무의미하다.
