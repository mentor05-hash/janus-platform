## 3. "저장 경로 부재" grep 증빙 (모듈 소스, 테스트 제외)

대상: `src/{guard,index,policy,reasons,types}.ts` — 판정 함수는 버퍼를 받아 메모리에서만 훑고 폐기.

| 카테고리 | 정규식 | 검출 |
|---|---|---|
| fs import/require | `from ['"](node:)?fs` \| `require('fs')` | **0건** |
| fs write | `writeFile\|appendFile\|createWriteStream\|writeFileSync\|.write(\|mkdir\|openSync` | **0건** |
| DB insert/save | `insert\|save\|persist\|upsert\|prisma\|typeorm\|knex\|repository` | **0건** |
| 로깅(내용 유출) | `console.\|logger.\|log(` | **0건** |
| 네트워크 송출 | `fetch(\|axios\|http.request\|https.request` | **0건** |

→ 원본·추출 텍스트를 파일·DB·로그·네트워크 어떤 경로에도 영속화하지 않음(지시서 §1-2 무취급·비보존).

## 4. 무취급 원칙 준수(테스트 데이터)

테스트는 전부 **모의 서식 문자열**만 사용 — 실제 생기부 파일·실 PII는 테스트에도 무사용(지시서 §0 주의). 각 모의 데이터에 "실데이터 아님" 표기.
