## 0. 시작 전 30초 체크

```bash
git ls-remote origin refs/heads/feat/consulting-intake   # 진짜 base tip
gh pr list --state open                                   # 진짜 열린 PR
git config --get core.hooksPath                           # .githooks 여야 한다
git worktree list                                         # 지금 어느 트리에 있나
```

세 번째 줄이 비면 시크릿 스캔이 꺼진 것이다 — `bash scripts/setup-hooks.sh`.

**이 저장소는 워킹트리를 여러 세션이 공유한다.** 이 세션에서도 작업 중 다른 세션 커밋이 두 번 끼어들었다.
커밋 전에 `git status` 로 **내가 만들지 않은 변경**이 섞이지 않았는지 보고, 남의 브랜치를 건드릴 일이 생기면
**격리 워크트리**(`git worktree add`)에서 한다.

### ⚠ 재시드 함정 — 이걸 모르면 노출이 되살아난다

시드는 `ON CONFLICT ... DO UPDATE SET pw_hash` 로 비밀번호를 **강제로 덮어쓴다**.
그래서 `JANUS_DEMO_ADMIN_PW` **없이 재시드하면 관리자 비번이 공개값 `dev-password!` 로 되돌아간다** —
화면에도 로그에도 아무 표시가 없다. 데모 DB 를 다시 시드할 일이 생기면 반드시:

```bash
JANUS_DEMO_ADMIN_PW='<운영값>' npm run seed        # ts-node 환경
JANUS_DEMO_ADMIN_PW='<운영값>' npm run seed:prod   # 컨테이너
```

`prisma/seed-base.sql` 은 **SQL 이라 ENV 를 못 읽는다** — 공개 데모에 쓰면 안 된다(파일 헤더에 경고 있음).

### ① W2 D4 무료 배치표 Pages 배포 — **선행 3건 미충족(2026-08-08 실측)**

도메인은 풀렸고 자리표시자도 확정됐지만, **아직 착수할 수 없다.** 확인한 것:

| 선행 | 상태(2026-08-08) | 안 되면 무슨 일이 |
|---|---|---|
| 마스터 센티넬 태깅 | ❌ 마스터 5종 전부 `JANUS-TIER` 0건 · strip 대상 0건 | `tier_verify.py:91` `require_stripping` 에 걸려 **검증 실패 → 배포 불가** |
| janus-public 원천 | ❌ `30_public/` 에 `README.txt` 하나뿐 · git 저장소 아님 | Pages 가 배포할 원천이 없다 |
| 캘린더 확정 | ❌ 9건 전부 `provisional` | O210 이 정한 **공개 배포 조건** 위반 |

첫 줄이 핵심이다. 무료판은 **빌드는 되지만 검증에서 죽는다** — O201 이 만든 방어가 정확히
"제거 0건인데 통과"를 막기 때문이고, 이건 W2 D2 선행 ①(마스터 센티넬 태깅) 그 자체다.
확인 방법(내용은 볼 필요 없다, 표식 유무만):

```bash
grep -c "JANUS-TIER" <마스터.html>                       # 0 이면 아직 미태깅
grep -c "__JANUS_RAWDATA__\|__JANUS_CUTS__" <마스터.html>  # 둘 다 0 이면 배포 불가
```

⚠ **Cloudflare Pages 프로젝트 생성과 커스텀 도메인 연결은 대시보드 작업이라 세션이 못 한다.**
사용자가 직접 해야 하고, 세션은 그 전후의 저장소·빌드·검증을 맡는다.

선행이 풀린 뒤 쓸 **자리표시자 확정값**:

| 항목 | 확정값 |
|---|---|
| Pages 프로젝트 | **`ianuspath`** → 기본 주소 `ianuspath.pages.dev` |
| 원천 | **janus-public 저장소 `main` 브랜치** |
| 커스텀 도메인 | `ianuspath.com` · `www.ianuspath.com` |
| **완료 기준** | **로컬 서버를 내린 상태에서 무료 배치표가 열릴 것** |

완료 기준이 핵심이다 — 맥 스택이 떠 있으면 "열린다"가 엣지에서 서빙된 증거가 되지 못한다.
반드시 로컬을 내리고 확인한다.

무료판 빌드는 **이 값들을 ENV 로 주고** 돌린다(값은 repo 에 커밋하지 않는다 — O210 원칙):

```bash
JANUS_ALLOWED_HOSTS="ianuspath.com,www.ianuspath.com,*.ianuspath.pages.dev" \
JANUS_CANONICAL_ORIGIN="https://ianuspath.com" \
  python3 ops/placement/tier_build.py --src <마스터.html> --tier free
python3 ops/placement/tier_verify.py dist-tier/free --tier free   # 비-0 이면 배포 금지
```

- `*.ianuspath.pages.dev` 를 **빼지 말 것**: Pages 미리보기는 `<해시>.ianuspath.pages.dev` 로 나가는데,
  이게 빠지면 미리보기가 미러로 판정돼 "야누스 공식 주소가 아닙니다" 안내를 띄우고 튕긴다 —
  하필 배포를 검증하는 그 순간에 걸린다.
- 사이드카 `janus-build.json` 을 **HTML 과 함께** 올려야 한다. 하나만 올리면 배포 감지 배너가 계속 뜬다.
- 상세: `ops/placement/README.md` §2-1-1.

### ② 입시 캘린더 공고 대조 (①과 함께 끝나야 공개 가능)

`packages/exam-calendar/src/events.json` 의 **2027학년도 9건이 전부 `status: provisional`** 이다.
관례 기반 추정(예: "수능 = 11월 셋째 주 목요일")이고 평가원·대교협 공고와 대조한 적이 없다.
그래서 무료판 D-day 칩에 **`잠정` 배지**가 함께 나간다.

할 일: 공고와 대조 → `status: confirmed` + `source` 에 공고 근거 + 최상위 `verified_against`·`verified_at` 채우기
→ `npm run gen:calendar` 로 TS 상수 재생성(CI 가 `--check` 로 동기화를 강제한다).

**공개 배포 조건이다**(O210 에 명시). 잠정 날짜로 D-day 를 공개하면 틀린 카운트다운을 보여주게 된다.

## 5. 이 세션이 새로 배운 함정

| 겉보기 | 실제 |
|---|---|
| 테스트가 "✅ 전체 통과" | **단언이 0건 실행돼도 그렇게 나온다.** 스니펫 추출이 빈 문자열이면 "허용 호스트 → 통과" 류 단언은 전부 통과한다. → `MIN_CHECKS` 하한 + 음성 대조 + 추출물 실물 확인(O211) |
| 게이트가 초록 | **게이트가 죽어 있어도 초록이다.** 기능을 하나씩 끈 빌드로 게이트가 실제 비-0 이 되는지 확인해야 한다(`gate_negative_sim.mjs`) |
| 워크스페이스 패키지 추가 | `package-lock.json` 을 같이 안 고치면 **모든 CI 잡의 `npm ci` 가 죽는다**. 고칠 때 `npm install --package-lock-only` 를 macOS 에서 돌리면 **다른 플랫폼용 `@esbuild/*` 22개를 락파일에서 떨궈** 리눅스 러너를 깨뜨린다 — 링크 엔트리 2개만 손으로 넣는다 |
| 브랜치 CI 가 초록이었다 | 마지막 성공이 **2주 전**일 수 있다. 남의 브랜치를 base 로 PR 을 열기 전에 그 브랜치의 최근 CI 를 본다 |
| 돌연변이 시험 | **커밋 후에 한다.** 커밋 전에 하면 `git checkout --` 원복이 아직 안 담긴 구현까지 지운다(이번에 겪음) |
