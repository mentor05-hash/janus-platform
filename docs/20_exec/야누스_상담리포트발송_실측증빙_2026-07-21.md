# 상담 리포트 발송·수신 실측 증빙 (2026-07-21)

> "완료"의 정의 = 실측(CLAUDE.md §3). 선생님이 상담 기록을 최종 저장한 뒤
> 학생·학부모용 요약을 만들어 검수→승인→발송하고, 학생 계정에서 열람되는
> 전 과정을 로컬 풀스택(Playwright)으로 눌러 캡처했다.

## 대상 변경 (커밋 2b9ea66)
- **발송 버튼 중복 클릭 방어** — 발송 즉시 낙관적으로 `status='sent'` 반영해
  재조회 지연 중에도 버튼 즉시 잠금 + `send()` 에 `status==='approved'` 가드
  + 발송 중 버튼 텍스트 `발송 중…`. 웹·모바일 동일.
- **용어 정리** — 선생님 노출 문구의 개발 약어 `2뷰` → `학생·학부모용 요약`
  (내부 코드·타입명은 유지).

## 환경
- 로컬 postgres 16 + redis + api(:3000, dist) + web(:5173, vite dev).
- 마이그레이션 82개 전량 적용(0081 consult_report_view · 0082 tutor_source 포함).
- 시드: `teacher01`(선생님더미) · `student01`(학생더미).
- 픽스처: 두 계정 간 완료(booking DONE) + 최종 저장(save_state='final') 상담 기록.
  공개 필드(core_summary/homework/future_dir) + **내부 memo**("진도 압박 주의 —
  학생 노출 금지") + guardian_visible=true.
- LLM_PROVIDER=none → 규칙 폴백(mock)으로 요약 생성.

## 시나리오·결과

| # | 단계 | 화면(선생님/학생) | 결과 |
|---|---|---|---|
| 1 | 검수함 진입 | 선생님 `/app/reports` | 상담이 `메모 기반` 칩으로 노출 ✅ |
| 2 | 요약 생성 | `✨ 학생·학부모용 요약 만들기` | 상담 기록 원천에서 학생·학부모 초안 생성 ✅ |
| 3 | 승인 | `승인` | 상태 `승인됨`, 하단 `초안 재생성`·`📤 학생에게 발송` 노출 ✅ |
| 4 | **발송** | `📤 학생에게 발송` | 상태 `발송됨`, **발송·재생성 버튼 완전 소멸**(재발송 불가), 입력란 읽기전용 ✅ |
| 5 | 학생 열람 | 학생 `/student/reports` | 리포트 도착(`NEW`), 학생용/학부모용 탭 열람 ✅ |
| 6 | **내부 memo 미노출** | 학생 화면 전체 | memo("진도 압박…") 문자열 **미검출**(memoLeaked=false) ✅ |

- API 확인: `consult_report.status='sent'`, `sent_at` 스탬프, `/media/reports/student`
  가 해당 리포트 반환(teacherName·category 포함).
- Playwright 콘솔: `pageerrors: []`, `seesCovered: true`(학생이 공개 요약 정상 확인).
