# 무료판 배포 전 점검표 v1 (2026-07-26)

> 위치 `docs/20_exec/` · 근거: 실행계획서 **W2 D6~7** `[DOC] 무료판 배포 전 점검표(저작권·면책·워터마크·로그) 작성`(미체크) · **W4 게이트 판정** 조건 `무료판 법적 점검표 이상 없음`.
> 백로그 **B013**. 관련 항목: B012(면책·워터마크 실삽입) · B009·B010(코드 반입) · B024~B029(티어 게이팅·패리티) · B002/N24(무료 노출 수) · B007(법률 질의서).
> **이 문서의 목적**: W4 게이트를 "판정 가능"하게 만드는 것. 지금까지는 게이트 조건이 참조하는 점검표 자체가 없어 통과/미통과를 물리적으로 판정할 수 없었다.

## 0. 판정 규칙

- **완료의 정의 = 실측.** 각 항목은 `확인 방법`대로 실행해 `증빙`을 남겨야 통과다. 증빙 없는 "확인했음"은 미완료로 본다(실행계획서 §4).
- 판정값은 **통과 / 미통과 / 해당없음 / 반입대기** 4가지. `반입대기`는 대상 코드가 아직 repo 에 없어 물리적으로 판정 불가한 항목(B009·B010 해소 시 재판정).
- **하나라도 미통과면 무료 공개(소프트 런칭 W6)를 하지 않는다.** 이 점검표는 권고가 아니라 게이트다.
- 판정자·일자를 각 항목에 기록한다. 재배포·산출물 갱신 때마다 **전 항목 재판정**(§7 재판정 트리거).

## 8. 현재 상태 요약 (2026-07-26 갱신)

**게이트 통과 불가 — 단, 블로커가 5건 → 2건으로 줄었다.**

해소된 것:
1. ✅ **무료 노출 수(N24)가 더 이상 블로커가 아니다** — 정책값으로 분리(`tier-policy.config.json` + `system_setting` override, O48). 법률 회신 전 보수적 잠정치(구간별 3개·수치 마스킹·검색/상세 잠금)로 시작하고, 회신 후 **코드 배포 없이** 관리자 화면(`PUT /api/v1/admin/free-exposure`)에서 조정한다. 안전선(구간별 5개)을 넘기려면 회신 근거가 필요하도록 서버가 거부한다.
2. ✅ **§1·§2·§3의 기계 검사가 자동화됐다** — `./ops/publish-gate.sh <dist>`. 구 브랜드 잔재·회원 데이터 물리 부재·면책 전 화면·워터마크·시크릿 혼입을 배포 전에 차단한다. `display:none` 으로 숨긴 회원 데이터도 잡는다.
3. ✅ **배포 경로가 확보됐다** — `./ops/publish-public.sh` (GitHub Pages, 공개 repo). Cloudflare 계정(B014) 없이 "맥이 꺼져도 무료판 서빙"이 가능하다.

남은 블로커 2건:
1. **판정 대상 산출물이 없다** — 배치표 생성기(`gen_jeongmil.cjs`)·`야누스_사이트` 미반입(B009·B010). 게이트를 돌릴 `<dist>` 가 아직 없고, B012(면책·워터마크 실삽입)도 그래서 대기 중이다.
2. **법률 검토 미착수**(§6-1) — B007 질의서로 발송하면 리드타임이 시작된다. 회신은 §1-2 상향/§4-3 보관기간 확정에 반영한다.

→ 선결 순서(갱신): **B009·B010 코드 반입 → B012 삽입 → `publish-gate.sh` 실행·전 항목 판정 → `publish-public.sh` 로 공개 → 법률 회신 반영 재판정.**
법률 회신은 이제 **공개의 선행이 아니라 공개 후 조정 사유**다(잠정치가 보수적이라 회신이 늦어도 런칭이 밀리지 않는다).
