# 야누스 도메인 주소 배치도 — ianuspath.com (2026-08-12)

> 도메인 확보(2026-08-08) 후 **어느 호스트에 무엇을 둘지**의 목표안. 현황·운영 정보는 `docs/접속_주소_정리.md`,
> 고정 주소를 얻기까지의 경로 비교는 `야누스_고정주소_배포계획_2026-08-06.md`(A·B·C안)에 있다. 이 문서는 그 위에
> **주소 체계 하나만** 다룬다.
> 결정: O181·O182·O183 · 미결: N48·N49 (Decision-Register)
> ⚠ **이번 회차에 DNS·배포는 건드리지 않았다** — apex·www 개통은 보류(사용자 판단, 2026-08-12).

## 0. 요약

- 명명 규칙은 **1단계 서브도메인 + 역할 이름**으로 고정한다. 데모는 `demo-*` 접두사, 실서비스는 역할명 그대로(**O181**).
- **공개된 얼굴은 apex + www** — 마케팅 랜딩을 Access 밖 정적 호스팅으로 둔다(**O182**). 개통 시점은 보류.
- 관측 스택(Grafana·Prometheus·Alertmanager)은 **공개 주소를 주지 않는다**(**O183**).
- 지금 `ianuspath.com` 은 **외부인이 볼 수 있는 페이지가 0개**다 — 전부 Cloudflare Access 명단제 뒤에 있다.

## 1. 제약 — 주소를 정하기 전에 걸리는 것

| # | 제약 | 결과 |

| 3 | 티어 정책 — **무료판만 공개** | `dist-tier/{member,paid,consultant}/` 는 커밋·배포 금지. 공개 호스트에 올릴 수 있는 산출물은 `dist-tier/free/` 뿐 (CLAUDE.md §4) |

| 5 | 현재 배포 경로는 A안(명명된 터널) | 오리진이 이 맥이다 — **맥이 꺼지거나 잠들면 전부 죽는다**. 공개 얼굴(apex·www)을 여기에 얹으면 안 되는 이유이기도 하다 → 정적 호스팅(Pages) 분리 |

## 3. 현황 — 실측 (2026-08-12)

공개 주소로 인증 없이 요청했을 때의 응답. `302` = Access 로그인으로 리다이렉트(= 외부인은 못 봄).

| 대상 | 공개 | 로컬 |
|---|---|---|
| `demo/` (랜딩) · `/demo` · `/services` · `/placement` · `/kairos` · `/login` | **302** | 200 |
| `demo/api/v1/health` | **302** | 200 |
| `demo-m/` | **302** | — |
| `demo-rooms/api/rt/v1/health` | **200** | 200 |
| `ianuspath.com` · `www` | **DNS 레코드 없음** | — |

> ⚠ Access 적용(2026-08-08) 전에는 **비로그인 공개**였던 랜딩·서비스 소개·무료 배치표 미리보기까지
> 지금은 전부 명단제 뒤에 있다. 의도된 상태이지만 "도메인이 있다 = 공개된 얼굴이 있다"는 아니다.

## 5. 이행 순서 (제안)

1. **마케팅 표면 정리** — `marketing/src` 9장과 SPA `/services` 중 무엇이 정본인지 먼저 정한다. 이게 안 정해지면 apex 에 뭘 올릴지가 안 정해진다.
2. **N48 결정** — 무료 배치표를 www 하위 경로로 둘지 별도 호스트로 둘지. 호스트를 늘리지 않는 쪽(하위 경로)이 기본값으로 무난하다.
3. **apex·www 개통** — Pages 프로젝트 + DNS. Access 밖. (보류 중 — 사용자 판단)
4. **실서비스 이름은 C안 착수 시점에** — `app`·`m`·`rooms`(+`api`?). 그전까지는 예약만.

## 6. 결정·미결

| 번호 | 내용 |
|---|---|
| **O181** | 주소 명명 = **1단계 서브도메인 + 역할 이름**. 데모는 `demo-*` 접두사(`demo`·`demo-m`·`demo-rooms`), 실서비스는 역할명(`app`·`m`·`rooms`). 근거: Universal SSL 와일드카드가 한 단계까지(제약 1) — 2단계(`m.demo.…`)는 TLS 에서 끊긴다 |
| **O182** | **공개된 얼굴은 apex + www** = 마케팅 랜딩, **Access 밖 정적 호스팅**(Pages). 맥 의존 오리진(A안)에 얹지 않는다 — 공개 페이지가 맥 전원에 묶이면 안 된다. 개통 시점은 보류(2026-08-12) |
| **O183** | 관측 스택(Grafana·Prometheus·Alertmanager)·데이터 계층(PostgreSQL·Redis)에는 **공개 주소를 부여하지 않는다**. 접근이 필요하면 사설망·SSH 터널 |
| **N48** | 무료 배치표 공개판(`dist-tier/free/`)을 **www 하위 경로**에 둘지 **별도 호스트**로 뺄지 |
| **N49** | 실서비스에서 API 를 **별도 호스트(`api.`)로 분리**할지, 지금처럼 web nginx `/api` 프록시를 유지할지 |
