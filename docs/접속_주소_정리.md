## 자동 로그인 링크 패턴 (데모 전용, VITE_DEMO_MODE=true)
- 회원 선택 화면: `{웹주소}/demo` — 카드의 `바로 로그인`(즉시 진입) · `링크 복사`(그 회원 딥링크)
- 회원별 딥링크(웹): `{웹주소}/login?u={아이디}&p=dev-password%21`
- 회원별 딥링크(모바일 :8090): `{모바일주소}/?u={아이디}&p=dev-password%21` (EXPO_PUBLIC_DEMO_MODE=true 로 export 한 번들에서만)

## 공개 터널 — 외부에서 접속시키기
```bash
bash ops/demo-public-link.sh          # 스택 기동 + 프런트 최신화 + 터널 3개 + 링크 출력
bash ops/demo-public-link.sh --stop   # 터널만 종료(외부 접속 즉시 차단, 스택은 유지)
```
- 웹(8080)·모바일(8090)·상담룸(3100) 각각 cloudflared quick tunnel. 웹/모바일 origin 의 nginx 가 `/api` 를 api 컨테이너로 프록시하므로 백엔드 터널은 따로 필요 없다.
- 상담룸은 브라우저가 룸 서비스에 직접 붙으므로 스크립트가 `ROOMS_PUBLIC_URL=<룸터널>` 로 api 를 재기동한다.
- **quick 터널은 프로세스가 사는 동안만 유효** — 맥이 잠들거나 재실행하면 주소가 바뀐다. 고정 주소가 필요하면 named tunnel(도메인 필요).
- **저작권 데이터(`JANUS_DATA_DIR_HOST`)는 공개 터널에 붙이지 않는다**(CLAUDE.md §4) — 배치표 허브는 '준비 중'으로 보인다.
- 공개 URL 을 아는 사람은 마스터관리자까지 아무 회원으로나 들어올 수 있다. 데모가 끝나면 `--stop`.

## 프런트 반영 두 가지 경로
- **이미지에 굳히기(정식)** — `docker compose -f docker-compose.full.yml build web mobile` 후 `up -d web mobile`. 컨테이너를 새로 만들어도 유지된다. base 이미지(`nginx:alpine`·`node:20-alpine`)가 로컬에 없으면 pull 에 십수 분 걸릴 수 있다(막힌 게 아니라 느린 것 — 기다리면 된다).
- **컨테이너에 바로 넣기(빠름)** — 위 스크립트가 자동 수행. 워킹트리를 즉시 반영하지만 컨테이너 수명 동안만 유효.
```bash
VITE_DEMO_MODE=true npm run build --workspace apps/web
docker cp apps/web/dist/. janus-platform-web-1:/usr/share/nginx/html/
```
- 모바일은 `EXPO_PUBLIC_DEMO_MODE=true npm run export:web --workspace apps/mobile` 로 export 해야 역할 칩·`?u=&p=` 자동 로그인이 살아난다(플래그 없이 export 하면 데모 분기가 트리셰이킹돼 사라짐).
