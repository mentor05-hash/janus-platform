## 공개 고정 주소 — Cloudflare 명명된 터널 (2026-08-08 개통·실측)

브랜드 도메인 `ianuspath.com`. 재기동해도 안 바뀐다.

| 주소 | 로컬 | 용도 |
|---|---|---|
| **https://demo.ianuspath.com/demo** | :8080 | 체험 입구(회원 선택 → 바로 로그인) |
| `https://demo.ianuspath.com` | :8080 | 야누스 메인·전 역할 웹 (nginx 가 `/api` 프록시) |
| `https://demo-m.ianuspath.com` | :8090 | 모바일 웹(학생·학부모) |
| `https://demo-rooms.ianuspath.com` | :3100 | 실시간 룸 — `.env` 의 `ROOMS_PUBLIC_URL` |

- 터널 하나(`janus-demo`)가 ingress 규칙으로 세 호스트를 나눠 받는다 — 설정 `~/.cloudflared/config.yml`.
- launchd `com.janus.cloudflared` 가 로그인 시 자동 기동.
- **apex(`ianuspath.com`)·`www` 는 비워 뒀다** — 마케팅·랜딩이 쓸 자리. 매칭 안 되는 호스트는 404.
- ⚠ **서브도메인은 한 단계만 쓴다.** Cloudflare 무료 인증서(Universal SSL)의 와일드카드가
  `*.ianuspath.com` **한 단계까지**라 `m.demo.ianuspath.com` 같은 2단계는 DNS 는 풀려도 TLS 에서 끊긴다
  (실측 2026-08-08: 2단계 → curl exit 6). 그래서 `demo-m`·`demo-rooms` 로 폈다.
  2단계를 쓰려면 Advanced Certificate Manager(유료)가 필요하다.
- ⚠ **Docker 스택이 떠 있어야 한다**(없으면 502). compose 전 서비스 `restart: always` + Docker Desktop 자동시작.
- ⚠ **맥이 꺼지거나 잠들면 죽는다.** 상시 가동은 [고정주소 배포계획 §4](20_exec/야누스_고정주소_배포계획_2026-08-06.md).
- ⚠ **URL 을 아는 사람은 누구나 들어온다.** 브랜드 주소라 더 알려지기 쉽다 — 계획서 §6-1(Cloudflare Access) 참조.

```bash
cloudflared tunnel info janus-demo                                  # 터널·연결 상태
bash ops/demo-public-link.sh --no-build                             # 스택+주소 한눈에
launchctl unload ~/Library/LaunchAgents/com.janus.cloudflared.plist # 공개 중단
```

### 예비 경로 — Tailscale Funnel
도메인 확보 전 쓰던 `janus-demo.taildfe36f.ts.net`(웹 443 · 모바일 8443 · 룸 10000)이 아직 살아 있다.
launchd `com.janus.tailscaled`. 정리하려면 `launchctl unload ~/Library/LaunchAgents/com.janus.tailscaled.plist`.

### 관리자 계정 잠금 (데모 빌드)
`admin01`·`hq01`·`master01`·`hr01` 은 체험 동선에서 막혀 있다 — 카드 클릭 · 딥링크(`?u=&p=`) · 로그인 폼 셋 다.
판정은 `apps/web/src/auth/demoAccounts.ts` 한 곳. **이건 화면 게이트이지 인증이 아니다** — 이것만으로는
`curl` 로 공개 비번을 던져 토큰을 받는 경로가 열려 있다.

**실차단은 시드 쪽**이다 — `JANUS_DEMO_ADMIN_PW` 를 주고 시드하면 이 4개만 공개값이 아닌 비번으로 심겨
API 로도 안 열린다(`apps/api/src/config/demo-admin-accounts.ts`). 두 목록이 어긋나면 api 유닛테스트
`demo-admin-accounts.spec.ts` 가 실패하므로 **한쪽만 고치지 말 것**. 공개 주소로 데모를 열 때는 이 ENV 를
주고 재시드하는 게 맞다(스크립트가 미설정이면 경고를 출력한다).

## 임시 터널 — cloudflared quick tunnel (예외 경로)
명명된 터널이 있는 지금은 쓸 일이 없다. 다른 기기·다른 자리에서 급히 열어야 할 때만.
```bash
bash ops/demo-public-link.sh --quick-tunnel  # 임시 터널 3개 추가 개통
bash ops/demo-public-link.sh --stop-quick    # 임시 터널만 종료(브랜드 주소는 유지)
```
- ⚠ `--quick-tunnel` 은 `ROOMS_PUBLIC_URL` 을 임시 주소로 덮어써 api 를 재기동한다 → **브랜드 룸 주소가 깨진다.** 원복은 옵션 없이 `bash ops/demo-public-link.sh`.
- 웹/모바일 origin 의 nginx 가 `/api` 를 api 컨테이너로 프록시하므로 백엔드 터널은 따로 필요 없다.
- quick 터널은 프로세스가 사는 동안만 유효하고 재실행하면 주소가 바뀐다.
- ⚠ **배치표 허브 데이터는 기본으로 붙는다** — 루트 `.env` 의 `JANUS_DATA_DIR_HOST=~/janus/20_data` 를 compose 가 자동으로 읽어, full.yml 단독 기동만으로도 20_data **전체**가 api 컨테이너에 읽기전용 마운트된다. "안 붙였다"고 가정하지 말고 `GET /api/v1/placement-hub/list` 의 `available` 로 확인할 것.
  - 공개 터널에서 실제로 나가는 것: `tier=free` 표(격차 리포트)는 **비로그인 공개**, `tier=paid` 표는 로그인+티어/상품권한+1회용 티켓+워터마크+감사+일일 40회 상한. manifest 밖 파일·`audience=internal` 자료는 안 나간다.
  - `/demo` 가 `paidall` 계정을 아무에게나 내주므로, **링크를 아는 사람은 유료 배치표까지 열람 가능**하다(워터마크·감사는 남음). 감수할 수 없으면 아래 범위 축소를 쓰거나 터널을 닫는다.
  - 범위 축소(공개 시 권장) — 컨테이너에 `placement-hub/` 만 넣고 raw·internal·dist_restricted 는 제외:
    ```bash
    mkdir -p janus-data/placement-hub   # 겹쳐붙일 마운트지점(최초 1회)
    docker compose -f docker-compose.full.yml -f docker-compose.hub.yml up -d api
    ```
- ⚠ **씬-슬라이스 검색은 사실상 빈 상태** — `placement-hub/slices/jeongsi-2027.json` 이 4행짜리 샘플이고 `susi`·`jeongsi-2026` 슬라이스 파일은 아예 없다. 허브의 검색 탭은 "일치하는 항목이 없어요"만 뜨고, 실제 열람은 `전체표로 보기`(티켓 → 전체 HTML) 경로로만 된다. O76 이 의도한 "전체 파일 대신 검색 행만" 방어가 데이터 미비로 작동하지 않는 상태 — 슬라이스 생성이 데이터 트랙 숙제로 남아 있다.
- 관리자·HR 원터치 진입은 위 §관리자 계정 잠금으로 막혀 있다(화면단 한정). 데모를 닫으려면 터널을 내린다.

## 프런트 반영 두 가지 경로
- **이미지에 굳히기(정식)** — `docker compose -f docker-compose.full.yml build web mobile` 후 `up -d web mobile`. 컨테이너를 새로 만들어도 유지된다. base 이미지(`nginx:alpine`·`node:20-alpine`)가 로컬에 없으면 pull 에 십수 분 걸릴 수 있다(막힌 게 아니라 느린 것 — 기다리면 된다).
- **컨테이너에 바로 넣기(빠름)** — 위 스크립트가 자동 수행. 워킹트리를 즉시 반영하지만 컨테이너 수명 동안만 유효.
```bash
VITE_DEMO_MODE=true npm run build --workspace apps/web
docker cp apps/web/dist/. janus-platform-web-1:/usr/share/nginx/html/
```
- 모바일은 `EXPO_PUBLIC_DEMO_MODE=true npm run export:web --workspace apps/mobile` 로 export 해야 역할 칩·`?u=&p=` 자동 로그인이 살아난다(플래그 없이 export 하면 데모 분기가 트리셰이킹돼 사라짐).
