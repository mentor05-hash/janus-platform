## 자동 로그인 링크 패턴 (데모 전용)
- 웹: `{웹주소}/login?u={아이디}&p=dev-password%21`
- 모바일: `{모바일주소}/?u={아이디}&p=dev-password%21`
- `!` 는 URL 인코딩 `%21`. `?u=&p=` 자동로그인은 `VITE_DEMO_MODE=true` 에서만 동작(비번 URL 노출 — 데모 한정).
