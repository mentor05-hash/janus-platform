## ② 접합계약 v1 (동결) — 경계 6개

플랫폼과 연결되는 경계를 명문화한다. **이 계약은 플랫폼 트랙에 테스트 19케이스로 박혀 있어, 재통합 시 위반이 자동 검출된다.** 배치표 트랙은 이를 준수만 한다(변경은 §2 규칙2).

- **C1 · 성적 입력** — `janus_score` v22 키(스펙 앵커 O43) + **`janus:score` 이벤트**. 엔진은 이 이벤트만 구독하면 자동입력 연동 완성. 키: `{gye, nb | (kor,mat,tam1,tam2), eng, han}` (gye∈{이과,문과}; nb=전국누백; 표점 4종 또는 nb 중 택1).
- **C2 · 티어 게이트** — SSO **`janus:sso` 이벤트**, 서비스 id **`baechipyo`**(레지스트리 시드 완료). **토큰 없으면 무료판 모드 필수**(민감 데이터 부재 빌드).
- **C3 · 계측** — 페이지 id **`baechi`**, **상담 전환 CTA id `consult-reserve` 필수**(핵심 지표). 계측 왕복(발화→수신) 확인 대상.
- **C4 · 산출물** — **dist-tier 4종**(무료/회원/유료/컨설턴트). **무료판만** janus-public **`/baechi/`** 경로로 배포(URL 불변).
- **C5 · 근거수치 출력** — **`janus_report` 계약**. evidence 객체에 **신뢰도(relTier) 필수** 포함(어디가 실측·다년·변동성 근거). 
- **C6 · 데이터/저작권 경계** — 원천 데이터는 `JANUS_DATA_DIR` 참조만. repo 반입·커밋 금지, **gitleaks** 통과, 재배포금지 워터마크·로그 유지.
