## 2. 야누스 현행과의 대조

| 큐브 요소 | 야누스 현재 | 판정 |
|---|---|---|
| 사진·텍스트 질문, 건당 과금 | qna_post(첨부 3장·크레딧 건당 과금) ✅ 구현 | 동등 |
| 채택·별점 | accepted→payroll 정산 ✅ 구현 | 동등(정산 연동은 우리가 우위) |
| 대학생 답변자 풀 + 소액 보상 | 리그 기획(§3: 3부 실적→2부 크레딧→1부 금전) — **미구현** | 큐브가 모델 유효성 입증 |
| 주간 무료 질문권(수강 번들) | 없음 — 크레딧 단일 | **갭(즉시 채택 권고)** |
| 실시간성·첫응답 시간 노출 | SLA 4점 타임스탬프 기획(§2) — 미구현 | 갭 |
| 해시태그·질문 아카이브 검색 | 통합검색 있음, Q&A 태그 없음 | 갭(부분) |
| 학습법·입시·진로 질문 카테고리 | 과목 문제 중심 | 갭(우리 상담 자산과 시너지 큼) |
| 인기 마스터 → 지정 질문 유도 | 지정 스코프 ✅ / 프로필 배지 미구현 | 갭(부분) |
| AI 즉답(콴다형) | LlmProvider 인프라 보유, Q&A 미연결 | **기회(큐브에도 없음)** |
| 답변 품질 도구 | (우리만) 화이트보드·board-core·renderBoardPng | **우리 고유 자산** |

## 3. 제안 — 채택 권고 순

### P1. 무료 질문권 번들 — ✅ **구현 완료(7/19)**
Premium/VIP 구독·상담/과외 상품에 **"주간 무료 질문 N건"**을 번들. 크레딧 경제는 유지하되, 주간 갱신되는 무료 쿼터를 먼저 소진 후 크레딧 과금.
- 효과: 구독 가치 상승(해지 방어) + Q&A 수요 부트스트랩(§0-1 "시착 장치" 가동) + "이번 주 질문권 2장 남음" 리마인드 = 재방문 트리거.
- 구현: entitlement/credit에 주간 갱신 쿼터(`qa.weeklyFreeQuota` 정책값) + createQuestion 과금 분기 + 배지 UI. N23~25(가격) 확정과 함께 수치 결정.

### P2. AI 즉답 1층 + 사람 답변 2층 — ✅ **구현 완료(7/20)**
구현: 등록=무료(status ai_pending, 선생님 비노출) → AI 풀이 즉시 → [충분해요(resolve-ai, 무과금)] / [선생님 답변 받기(request-teacher — 이 시점에 무료질문권/크레딧 소진·escalated_at 기록·지정선생님 알림)]. SLA 첫응답은 COALESCE(escalated_at, created_at) 기산. 계측 meta.ev: ai_enough / human_requested.
질문 등록 즉시 **AI 풀이 초안**(LlmProvider, "AI 풀이 — 참고용" 라벨)을 무료 제공하고, 화면에 [충분해요(해결)] / [선생님 답변 받기(크레딧)]를 제시.
- 효과: 콴다에 익숙한 학생의 즉답 기대 충족 + 쉬운 질문의 답변자 부하 제거 + AI→사람 전환이 자연 과금 퍼널(기획 §1-4 승격 경로와 동형). 큐브(사람만)·콴다(AI/검색만) 사이의 **하이브리드 포지션**.
- 구현: qna_answer에 `kind:'ai'` 행 또는 별도 필드, LlmProvider 프롬프트(과목·첨부 이미지), 전환 계측(ai_enough/human_requested).

### P3. 유사 질문 재사용 — ✅ **구현 완료(7/20)**
구현: 작성 폼 디바운스 → POST /qna/similar(해결 질문 문자 bigram Jaccard ≥0.18 상위 3) → 익명 열람 모달(GET /qna/similar/:id — 해결 건만·첨부 제외·질문자 비노출). 계측: similar_shown / similar_opened.
질문 작성 시 **기존 해결 질문 중 유사 건을 먼저 제시**("비슷한 질문의 답변을 무료로 볼까요?"). 이미 있는 유사도 인프라(qna_answer.similarity·sim_flagged)를 등록 전 단계로 확장.
- 효과: 답변 부하↓, 무료 가치 체감↑, 아카이브가 쌓일수록 서비스가 좋아지는 축적 구조(콴다 70억 Q&A의 축소판).

### P4. 화이트보드 답변 — ✅ **구현 완료(7/19)**
선생님 답변 화면에 **"🖊 필기로 풀이"** 버튼: 질문 사진을 배경으로 화이트보드를 열고, 풀이 필기 후 renderBoardPng 로 PNG 를 답변에 자동 첨부.
- 효과: 큐브 마스터의 손글씨 사진 답변 대비 압도적 가독성. 이번에 만든 board-core·📎 기록 인프라 그대로 재사용 — 신규 코드 최소.
- 확장: 학생이 그 답변으로 "상담 승격" 시 같은 보드로 이어서 실시간 수업(§1-4 ①과 접속).

### P5. SLA 배지·홈 위젯 — ✅ **구현 완료(7/19)** (+지정 질문 선생님 선택 UI 갭 해소)
타임스탬프 4점(§2) 기록 시작 + 선생님 프로필에 "평균 첫응답 ○분·만족도 ○점" 배지 + 학생 홈에 "진행 중인 내 질문" 카드.
- 큐브의 "4.95" 마케팅과 같은 문법. 데이터는 지금부터 쌓아야 8월에 쓸 수 있음.

### P6. 질문 카테고리 확장: 학습법·입시·진로 — 소규모
subject 에 비교과 카테고리 추가 + 해당 질문은 컨설턴트 풀로 라우팅. 큐브가 입증한 수요이고, 우리는 **배치표·진단·컨설턴트**가 이미 있어 답변 품질에서 이길 수 있는 영역. 진로 질문 → 배치표/진단 CTA = 버티컬 간 교차 판매.

### P7. (기존 기획 가속) 리그 = 대학생 답변자 풀 — 대규모, 시기 판단
큐브의 1.2만 마스터·건당 소액 보상은 우리 리그 기획(3부→1부)의 시장 검증 사례. 다만 공급자 모집·검증·정산 운영이 필요하므로 **실오픈(10월) 후 트래픽이 생긴 뒤** 착수 권고 — 그 전에는 P1~P6로 수요측을 다진다.

### 도입 안 함 (근거 기록)
- **QCC형 콘텐츠(선배 영상·칼럼)**: 커뮤니티 기획에 이미 포함 — 별도 트랙 불요, 콘텐츠 제작 리소스 대비 효과 낮음(1인 운영).
- **질문권 별도 화폐**: 크레딧 단일 경제 원칙 유지 — P1은 "무료 쿼터"이지 신규 화폐가 아님.
- **사진검색(OCR 유사문항)**: 콴다의 해자(대규모 문항 DB) — 정면 대결 불가. P3(자체 아카이브 유사도)로 대체.
