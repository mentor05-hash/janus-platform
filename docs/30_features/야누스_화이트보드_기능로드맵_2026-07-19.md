# 야누스 화이트보드 기능 로드맵 (벤치마크 기반)

> 작성: 2026-07-19 · 기준: 줌 화이트보드·굿노트·Explain Everything·미로 등 상용 화이트보드의 기능군을
> **1:1 과외·상담(간헐적 1:다 강의)** 맥락으로 걸러 정리. "이후에 추가하지 않아도 되도록" 전체 지도를 만들고,
> 1차분은 즉시 구현 완료(아래 ✅). 쌍둥이 4파일 규칙: 웹 2(예약/룸) + 모바일 2 — 공통 수정은 전수 반영.

## 1. 기능 지도 (필수 / 편의 / 우리 맥락에선 불필요)

### A. 필수 — 없으면 수업이 불편한 것 (전부 확보됨)

| 기능 | 상태 |
|---|---|
| 펜(필압)·형광펜·지우개(영역) | ✅ 기존 |
| 색상·굵기 선택 | ✅ 기존 (5색·4굵기) |
| 배경: 이미지·PDF(페이지 넘김)·카메라 촬영 | ✅ 기존 |
| 줌/팬(핀치·휠) | ✅ 기존 |
| 자동 저장 + 재입장 복원 | ✅ 기존 |
| 실시간 라이브 잉크(그리는 중 중계) | ✅ 기존 |
| 되돌리기(undo) | ✅ 기존(룸) → 예약 이식 완료 |
| **다시 실행(redo)** | ✅ **신규** — 새 획 확정 시 스택 무효(상대 충돌 방지) |
| **도형: 직선·화살표·사각형·타원** | ✅ **신규** — 드래그 두 점, 기존 Stroke 포맷 그대로(저장·중계 호환) |
| 레이저 포인터 | ✅ 기존(룸) → 예약 이식 완료 |
| 필기만/배경까지 분리 지우기 | ✅ 기존(룸) → 예약 이식 완료 |

### B. 편의 — 있으면 좋고, 우리 수업 시나리오에 유효한 것

| 기능 | 상태 | 비고 |
|---|---|---|
| **모눈/줄노트 안내선** | ✅ **신규** | 수학 좌표·글쓰기 지도용. 상대와 동기화(wb:grid), 배경 이미지 있으면 자동 숨김. 세션 한정(스냅샷 미저장) |
| **보드 PNG 내보내기** | ✅ **신규** | 상담 후 학생에게 오늘 필기 전달. 현재 화면 그대로 저장 |
| **넓게 보기(전체화면)** | ✅ **신규** | 960px 고정 → 96vw 토글 |
| **단축키 ⌘Z/⌘⇧Z** | ✅ **신규** | 입력 필드 포커스 중엔 무시 |
| 텍스트 상자(타이핑) | 백로그 W-T1 | 수식·긴 설명 타이핑. 입력 오버레이+렌더+동기화 — 중간 규모 |
| 여러 페이지 보드 | 백로그 W-T2 | 현재는 PDF만 페이지. 빈 페이지 추가/전환 — 스냅샷 스키마 확장 필요 |
| 상대 커서 위치 표시 | 백로그 W-T3 | 레이저가 80% 대체 중. 상시 표시 원하면 소규모 |
| 지우개 크기 미리보기 커서 | 백로그 W-T4 | 굵기 버튼이 지우개 크기도 조절함(현행) — 원형 커서만 추가하면 됨 |
| 획 선택·이동·크기조절 | 백로그 W-T5 | 객체 모델 전환 필요(대규모). 1:1 과외에선 우선순위 낮음 |
| 스냅샷 버전 히스토리(이전 저장본 복원) | 백로그 W-T6 | whiteboard_snapshot 이 이미 누적 저장 — 목록 UI만 |
| 템플릿(오답노트·4분면 등) | 백로그 W-T7 | 안내선의 확장. 야누스 진단 양식과 결합하면 차별화 |
| 모바일 앱 작성 도구 파리티(도형·레이저·redo UI) | 백로그 W-T8 | 모바일은 이번에 **표시 호환만** 확보(웹이 그린 도형 렌더). 작성 UI는 RN 툴바 확장 |

### C. 상용에 있으나 우리 맥락에선 도입 안 함 (근거 기록 — 재논의 방지)

- **스티키 노트·마인드맵·투표**: 협업 보드(미로)용. 1:1 과외 판서와 무관.
- **무한 캔버스**: 논리좌표 고정(900×620)이 저장·중계·모바일 호환의 근간. 페이지 추가(W-T2)로 대체.
- **동시 편집 충돌 해결(CRDT)**: 참여자 2~소수 + 획 단위 append 라 현행 wb:sync 로 충분. CRDT 는 과설계.
- **녹화**: 화상(M3 품질 관측·리포트) 트랙에서 세션 단위로 다룰 사안 — 보드 단독 녹화는 중복.

## 2. UI/UX 점검 — 발견된 문제와 조치

| # | 문제 | 조치 |
|---|---|---|
| 1 | 툴바 혼잡(버튼 20+개, 좁은 화면에서 2~3줄 랩) | 이번에 구분선 그룹화 유지 + 텍스트 버튼 축약(↶/↷). **후속 W-U1**: 도구군 팝오버(펜 옵션 통합)로 1줄화 |
| 2 | 되돌리기가 텍스트 버튼이라 멀고 단축키 없음 | ✅ ⌘Z/⌘⇧Z + 아이콘 버튼화 |
| 3 | 보드 크기 960px 고정 — 노트북에서 여백 낭비 | ✅ 넓게 보기 토글 |
| 4 | 화상 PIP가 보드 우상단 필기 영역을 가림 | 후속 W-U2: PIP 드래그 이동(현재는 위치 고정. O82에서 앵커는 수정됨) |
| 5 | 지우개 선택 시 커서가 crosshair 그대로 — 지울 범위 감이 없음 | 백로그 W-T4 |
| 6 | 도형 그리기 중 상대 화면엔 미리보기 없음(확정 시에만 표시) | 의도된 절충(도형은 순간 완성) — 불편 제기 시 partial 프로토콜 확장 |
| 7 | 저장 상태 표시가 작은 회색 텍스트 | 현행 유지(자동저장 신뢰) — 실패 시에만 눈에 띄게 하는 후속 W-U3 |

## 3. 프로토콜·호환 메모

- 도형은 **기존 Stroke JSON에 `shape` 필드 추가** — 서버·스냅샷·중계 무변경(서버는 획을 불투명 데이터로 취급).
- `wb:grid` 이벤트 신설: API 게이트웨이(예약)·룸 게이트웨이(이관) 양쪽 중계, 강의 모드에선 판서권자만 변경 가능.
- 모바일 앱은 도형 **렌더 호환** 확보(구버전 앱은 도형을 대각선으로 오렌더 — 앱 업데이트 배포로 해소).
- 레이저·안내선은 비영구(스냅샷 미저장) — 저장 대상은 확정 획+배경만(기존 규약 유지).

## 4. 권장 다음 순서

1. **W-T8 모바일 작성 파리티** — 태블릿 과외 시나리오면 우선순위 상향.
2. **W-U1 툴바 1줄화** — 기능이 늘어난 지금이 적기.
3. **W-T1 텍스트 상자** → **W-T2 다중 페이지** — 수업 밀도가 올라가면.
4. (구조) **쌍둥이 공용 컴포넌트 추출** — 이번 이식으로 4파일 동기화 비용이 더 커짐. 기능 추가가 일단락된 지금이 추출 적기.
