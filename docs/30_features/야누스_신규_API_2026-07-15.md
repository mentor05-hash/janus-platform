# 야누스 신규·변경 API 참조 (2026-07-15)

> 이번 세션(기능 심화 + 품질) 추가·변경분. 공통 규약: prefix `/api/v1`, JWT(access), 응답 `{data,meta}` / `{error:{code,message}}`, 금액 정수(원), UTC 저장·KST 표시.

## 1. 전역 통합검색

### GET `/search?q=<검색어>`
- 권한: 로그인 전원(@CurrentUser).
- 강좌·자료·커뮤니티·선생님을 한 번에 조회 — 각 도메인 서비스의 기존 조회(권한·공개범위 로직)를 재사용해 정규화. 그룹별 상위 6건.
- 빈 검색어(공백만) → `{ q, total: 0, groups: {} }`.
- 응답:
```jsonc
{ "q": "미적분", "total": 3,
  "groups": {
    "teacher":  [{ "type":"teacher","id":"…","title":"홍길동","subtitle":"수학·물리","subject":"수학","href":"/student/search" }],
    "lecture":  [{ "type":"lecture","id":"…","title":"미적분 개념 완성","subtitle":"미적분","subject":"수학","href":"/student/lectures" }],
    "community":[{ "type":"community","id":"…","title":"…","subtitle":"답변 2","subject":null,"href":"/student/community/board" }],
    "material": [{ "type":"material","id":"…","title":"…","subtitle":"프린트","subject":"국어","href":"/student/materials" }]
  } }
```
- href 는 웹 App.tsx 실경로와 정합(상수 `SEARCH_HREFS`, 회귀방지 spec 有). 선생님은 `/student/search`.

## 2. 약점 클리닉 추적·추이

### GET `/diagnostics/clinics`
- 권한: `@Roles('student')`. `:id` 라우트보다 먼저 선언(정적 우선).
- 본인 클리닉 시도(`is_clinic=true`)만, 오래된→최근. 반복 훈련 효과 확인용.
- 응답:
```jsonc
{ "attempts": [{ "id":"…","total":8,"correct":5,"score":63,"submittedAt":"…","parentAttemptId":"…" }],
  "count": 3, "avgScore": 60, "bestScore": 80, "improvement": 40 }  // improvement = 최근−최초, 표본 없으면 null
```
- 산출 로직은 순수함수 `summarizeClinic`(도메인, 유닛테스트 有).
- 관련 스키마(0061): `diagnostic_attempt.is_clinic`, `parent_attempt_id`. `POST /diagnostics/clinic` 시 두 컬럼 세팅.
- `GET /diagnostics/me` 응답에 `is_clinic` 플래그 노출.

## 3. 커뮤니티 실시간(소켓)

WebSocket path `/api/v1/socket.io`(nginx `/api/` 프록시 정합), JWT `auth.token`.

| 방향 | 이벤트 | 페이로드 | 설명 |
|---|---|---|---|
| client→server | `community:join` | `{ postId }` | 게시글 방 입장(로그인 전원 — 공개 Q&A) |
| client→server | `community:leave` | `{ postId }` | 방 퇴장 |
| server→client | `community:answer` | `{ postId, answerId }` | 새 답변 등록 시 방에 브로드캐스트 |
| server→client | `community:accepted` | `{ postId, answerId }` | 답변 채택 시 방에 브로드캐스트 |

- 서버: `POST /qna/community/:id/answers`·채택 시 `RealtimeGateway.emitToCommunity` 호출.
- 클라이언트(웹 CommunityBoardPage·모바일 CommunityScreen): 이벤트 수신 시 무깜빡임 재조회.

## 4. 상담 후기 상태

### GET `/bookings` · GET `/bookings/:id`
- 학생 뷰 응답에 `reviewed: boolean` 부가(완료 상담의 후기 작성 여부). 중복 후기 폼 방지용.
- 후기 등록(`POST /bookings/:id/review`)은 기존대로 중복 시 409, 교사 평점 재산정.

## 5. 알림 전체 읽음

### PATCH `/notifications/read-all`
- 권한: 본인. `@Patch(':id/read')` 보다 먼저 선언(정적 우선).
- 응답: `{ read: <처리건수> }`.

## 6. 강좌 후기(참고 — 앞선 배치)

- `GET /lectures/:id` 응답에 평균 별점·후기 목록·내 별점(`myRating`).
- `POST /lectures/:id/review` `{ rating, text? }` — 수강생, 강좌당 1회(unique).
