# 아우구르(Augur) 예측선 — 방법론 선언과 수렴성 설명

작성 2026-07-14 · 목적: "타 기관(고속 등)과 수치가 유사한 이유"에 대한 대외 설명 논리 + 독립화 로드맵

## 1. 즉시 사용 가능한 설명 프레임 — "통계 예측의 수렴성"

> **모든 성실한 통계 예측은 같은 곳으로 수렴합니다.** 대입 예측의 원천 데이터는 셋뿐입니다 — ① 대학이 공식 발표한 과거 합격선(어디가) ② 평가원 채점 통계(표점·백분위 분포) ③ 당해 모집요강(정원·군). 이 공개 원천에 표준 통계기법(다년 대표값, 모집단 변화 보정)을 적용하면, **어떤 기관이 계산해도 비슷한 선이 나옵니다.** 실제로 저희 검증에서 통계 기반 예측(초판)과 진학사(한 달 모의지원 후 최종)의 실측 적중도 대등했습니다(1091:1129) — 방법이 전혀 달라도 수렴한다는 뜻입니다. 야누스의 차이는 수치가 아니라 **방법의 공개와 검증**입니다: 1,851명 실제 합격자로 소급 검증한 오차(±4.2%p)를 성적표로 공개하고, 못 맞히는 구간은 '예측한계'로 표시합니다.

- 핵심 문장: "유사한 것은 베낀 것이 아니라, 같은 공개 데이터에 정직한 통계를 적용한 결과입니다. 다르게 나오는 예측이 있다면 그쪽이 설명해야 합니다."
- 보조 근거: 우리는 예측선을 그대로 쓰지 않고 자체 층(어디가 실측 모드, 조건부 중위값, 등수 정규화, 심리배지 4종, 원문 교정 165건)을 얹어 판정함 — 이미 산출물이 원본과 동일하지 않음.

## 2. 근본 해법 — 아우구르 엔진 v1 자체 산출 (로드맵)

재료와 방법 모두 이미 확보·검증됨. 파이프라인을 자체화하면 수치 유사성은 "독립 재현"이 됨:

| 단계 | 방법 | 상태 |
|---|---|---|
| 다년 대표값 | 어디가 공식 3개년 컷 → 조건부 중위값(변동 큰 단위 중위값 — 백테스트로 오차 14%↓ 검증) | 방법 검증 완료 |
| 모집단 보정 | 연도별 응시인원(미기+과탐 등) 등수 정규화 — P1 모듈 | 모듈 완성 |
| 정원 반영 | 2027 요강 정원·군, 급간 그룹화(P3) | 데이터 확보 |
| 누백 변환 | CALIB 곡선 역변환(백분위↔누백) | 보유 |
| 검증 | 실사례 백테스트 파이프라인 재실행 | 보유 |

산출 후 아우구르 예측선 = 100% 자체 파이프라인 → 감사 요청이 와도 전 과정 재현 가능. (9월 실채점 갱신 시점에 v1 가동 권장)
