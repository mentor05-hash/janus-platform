# 카카오 알림톡 발송 대행사 비교 — 본부 결정 지원 자료

> 조사일 2026-07-20 · 용도: 채팅·예약·질문답변 통지의 "선생님·학생이 놓치지 않게" 마지막 축(앱 밖 도달) — 알림톡 대행 계약 선택.
> 웹 검색 기반 — ⚠ 표시 항목은 공식 요금 페이지 직접 열람이 차단(403)되어 검색 결과·업계 통용가로 정리한 것이므로 **계약 전 각 사 요금표 원문 확인 필수**.

## 0. 개념 정리 (사용자 질문 "카카오채널 서비스 같은 개념?"에 대한 답)

- **알림톡** = 카카오톡 채널 기반의 **정보성 통지 메시지**(예약 확정·새 메시지 도착·답변 등록 등). 광고 불가, 수신자의 채널 친구추가 **불필요** — 전화번호만 있으면 도달. 카카오와 직접 계약이 아니라 **공식 딜러사(대행사)를 통해서만** 발송 가능.
- 큐브·클래스팅 등 교육 서비스들의 "카카오로 알림 오는" 그 방식이 맞음. 앱 푸시·인앱 배지(이미 구현)와 병행하는 **최후 도달 채널**.
- 발송 실패(카카오톡 미사용·차단 등) 시 **SMS/LMS 자동 대체발송(폴백)** 으로 도달률 100%에 근접시키는 게 표준 구성.

## 1. 종합 비교표

| 항목 | ① 솔라피 (SOLAPI) | ② 알리고 (Aligo) | ③ 비즈뿌리오 (다우기술) | ④ NHN Cloud (KakaoTalk Bizmessage) |
|---|---|---|---|---|
| 성격 | 개발자 친화 API 전문 | 저가·중소사업자 인기 | B2B 연동 전문(문자 점유율 1위 계열) | 엔터프라이즈 클라우드(SLA) |
| 알림톡 단가 | 구간별: 13원(~9,999건/월) → 10원(1만~) → 8원(10만~) → 7원(50만~) → 6.5원(100만~) | **≈6.5원**(충전형, 저가) ⚠ | 견적형(채널 통해 ≈6원 표기 사례) ⚠ | ≈8원선 ⚠(콘솔 요금표 확인 필요) |
| SMS 폴백 단가 | 자체 문자 단가 적용(구간별) ⚠ | SMS 8.4원 · LMS 25원 | 견적형 | SMS 별도 요금표 |
| 과금 기준 | 성공 건수(발송 실패 미과금) | 성공 건만 차감, 실패 즉시 환불 | 성공 건만 납부 명시 | 성공 건수 |
| API/SDK | REST + 다언어 SDK(Node 포함) — 연동 최속 | REST(단순), 웹 대량발송 UI 강점 | 연동 모듈 제공(사후 유지관리 무료) | REST + 콘솔, 대기업급 SLA |
| 월 기본료 | 없음(건당) | 없음(선충전) | 협의 | 없음(사용량) |
| 폴백 자동화 | 지원(알림톡 실패→SMS 자동) | 지원 | 지원 | 지원 |
| 비고 | 구간 단가는 최근 3개월 평균 발송량 기준 조정 | 최저가권이나 SDK·문서 품질은 솔라피 대비 단순 | 월 5만건 이상이면 단가 협상 여지 | 이미 NHN Cloud 인프라 쓸 경우 통합 이점 |

- 참고: 카카오 고객센터 공시 기준가는 **8원/건**(월 1만건 미만, VAT 별도, 성공 건수 기준) — 대행사 공개가는 통상 6.5~13원 사이에서 물량·협상으로 결정.

## 2. 공통 절차 (어느 대행사든 동일 — 리드타임 ~1주)

1. **카카오톡 채널 개설**(비즈니스 인증 — 사업자등록 필요) → 2. 대행사 가입·**발신프로필 연동** → 3. **템플릿 등록·심사**(카카오 검수 영업일 ≈2일, 반려 시 수정 재심사 — 변수 `#{이름}` 형식, 광고 문구 불가) → 4. API 키 발급 → 발송.
- 템플릿은 **사전 심사제**이므로 통지 유형별로 미리 등록해야 함. 야누스 초기 필요 템플릿(안): ①예약 확정/변경/취소 ②상담 1시간 전 리마인드 ③새 채팅 메시지 도착(부재중) ④질문 답변 등록 ⑤결제 요청/완료 ⑥리포트 발송 — 6종.

## 3. 야누스 예상 물량·비용 시뮬레이션

| 시나리오 | 월 발송량 | 솔라피(13원) | 알리고(6.5원) |
|---|---|---|---|
| 오픈 초기(학생 100명 × 월 20건 통지) | ~2,000건 | ≈26,000원 | ≈13,000원 |
| 성장기(학생 1,000명 × 월 20건) | ~20,000건 | ≈200,000원(10원 구간) | ≈130,000원 |

→ **초기 물량에선 어느 쪽이든 월 수만 원 수준** — 단가 차이보다 연동 속도·안정성이 결정 기준. 폴백 SMS는 실패분(통상 수 %)에만 발생하므로 미미.

## 4. 야누스 적용 구조 (기존 구현과의 연결)

- **채팅 자체는 플랫폼 안**(수익·기록·C1 필터 모두 플랫폼에 남김) — 알림톡은 "새 메시지 N건 도착 → [확인하기]" 통지 + **딥링크**(`…/student/chats?chat=…` — 이미 구현된 ?chat= 자동 오픈 경로 재사용)만 담당. 대화 내용 본문은 알림톡에 싣지 않음(개인정보 최소화).
- 연동 지점은 이미 어댑터로 준비됨: **`NotificationProvider`** — 현재 인앱(원장+소켓) 구현에 알림톡 provider 1개 추가하면 끝. 부재중 채팅 알림(10분 스로틀)·예약 알림 등 **기존 notification 원장 기록 시점에 훅**하면 되므로 도메인 코드 무변경.
- 발송 대상 전화번호: 가입 시 수집(인증) 전제 — 개인정보처리방침에 수탁사(대행사) 명시 필요.

## 5. 권고

1. **솔라피** — 1인 개발 체제에서 **연동 속도·문서 품질이 최우선**. Node SDK로 반나절 연동권, 성공 건 과금·폴백 자동. 초기 단가(13원)가 높지만 월 2천 건이면 차액 월 1.3만원 수준 — 무시 가능.
2. **알리고** — 물량 커진 뒤(월 수만 건↑) 단가 재협상 카드 또는 이중화(폴백 대행) 후보. 처음부터 최저가가 목적이면 이쪽.
3. NHN Cloud·비즈뿌리오 — 엔터프라이즈 SLA·대량 협상 단계(내년 이후)에 재검토.

**공통 전제**: ①채널 개설·템플릿 심사 리드타임 ~1주는 본부 몫(사업자 인증 필요 — 코드로 대체 불가) ②"완료" 판정은 실제 폰으로 알림톡 수신→딥링크 탭→채팅방 진입 실측으로.
