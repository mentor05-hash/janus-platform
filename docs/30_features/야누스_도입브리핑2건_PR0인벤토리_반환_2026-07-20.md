## B. 진단 기반 매칭 — PR-0 반환(부분 부재 → 매칭 코어는 착수 가능)

### PR-0 인벤토리 (코드 확인)
| 매칭 입력/후보 태그 | 실재 | 비고 |
|---|---|---|
| 격차리포트(JanusReport) | 있음 — `gye·target{univ,dept,cut}·gap.band·shortfall`(read 전용) | **과목 단위 약점은 격차리포트에 없음** — 실력진단(units/prescriptions)에 있음 |
| 상담사 과목 태그 | **있음** — `teacher_profile.subjects[]·sub_subjects[]·consult_types[]` | 과목 적합 매칭 가능 |
| 상담사 가용 시간창 | 있음 — work-schedule/slots·`teacher_monthly_hours` | 시간창 겹침 매칭 가능 |
| 상담사 스타일 태그 | 부분 — `strengths[]·modes[]` | 보조 신호 |
| 품질 신호 | 있음 — `rating·total_consult·re_request_rate·avg_response_min` | 콜드스타트 완화·정렬 |
| **목표대학 실적 태그** | **없음(⚠ §8 반환)** | 프로필에 "목표대학 합격 실적" 필드 부재 — 브리핑 §8-2·§8-3 |
| 예약 진입 API | 있음 — 기존 `/bookings` 플로우 | 상태머신 무변경으로 연결 |
| funnel_event | 있음 | shown→clicked→booked→completed 계측 |

### 결론 — 착수 가능 범위
- **매칭 코어(PR-1)는 착수 가능**: 입력 = 격차리포트(목표대·band·gye, read 전용) + 실력진단 약점 과목 + janus_score 대역. 후보 스코어 = **과목 적합(w1) + 시간창 겹침(w2) + 품질/평점(w3)**. 목표대학 실적(w) 은 필드 부재로 **이번엔 제외**하고 §8로 반환.
- **콜드스타트**: rating·total_consult 낮은 신규 상담사 소량 노출 슬롯(제안값, 설정).
- **거래 완결**: 카드에 연락처·외부 링크 없음, 다음 액션은 "상담 예약"만(기존 플로우).

### §8 본부 확인 필요
1. **격차리포트/janus_score 매칭 read 노출 범위** — 어떤 필드를 매칭 입력으로 읽어도 되는지(규약 변경 없이 읽기 범위만).
2. **목표대학 실적 태그 보강 여부** — 프로필에 실적 필드 신설 + 자기신고 vs 검증(설탭식). 없으면 매칭에서 "목표대학 실적" 가중치는 계속 제외.
3. **매칭 가중치·추천 인원수 N 초기값** — §4 예시(과목0.5·시간0.3·품질0.2), 실측 후 튜닝(설정).
4. **콜드스타트 노출 슬롯 규모**.
5. **추천 노출 위치·시점** — 격차리포트 뷰 내, 동기/비동기.
