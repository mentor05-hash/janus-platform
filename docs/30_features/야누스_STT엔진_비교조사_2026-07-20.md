## 2. 참고

- rtzr 자사 벤치마크(AI-Hub): 리턴제로 1·2위 → 클로바 → Whisper·Google 하위권. 자사 발표 감안, 파일럿 실측 권장. (blog.rtzr.ai/korean-speechai-benchmark)
- **아동·청소년 음성은 성인 대비 오류율 높음**(국내 논문, 4~6세 CER 비교) — 실제 상담 녹음 샘플로 엔진별 CER 실측 필수. (DBpia NODE11998390)
- ETRI 공공 API는 2025-06 종료 — 제외.

## 3. "미성년 학생 상담 녹음" 관점 권고 순위

1. **RTZR STT** — 국내·상담/통화 대화체 특화 성능 평판 1위·화자분리 기본·최저가권(분당 ≈17원). 단 API 고객 오디오의 보관·학습 조항을 계약 전 약관/DPA 로 확정할 것.
2. **CLOVA Speech** — 한국 리전 명시·국내법 준수 명시로 **컴플라이언스 설명이 가장 쉬움**. RTZR 과 실측 CER 로 최종 결정 권장.
3. **Daglo** — 국내·화자분리 지원이나 단가 비공개·제3자 검증 부족 → 파일럿 후보까지.
4. **OpenAI / Google** — 가격·인프라 매력적이나 **미성년 음성의 국외 이전**(개인정보보호법 §28-8 고지·동의 부담)이 커서 후순위. 굳이 쓰면 OpenAI 가 ZDR 기본이라 프라이버시 설명은 Google 옵트인 로깅보다 용이.

**공통 전제**: 어떤 엔진이든 ①학부모·학생 대상 처리위탁(+해외면 국외이전) 고지·동의 ②개인정보처리방침 수탁사 명시 선행. "완료" 판정은 실제 상담 녹음 30분 샘플의 엔진별 CER·화자분리 정확도 실측으로.

## 4. 코드 현황 (R2 어댑터 — 엔진 확정 전에도 완결)

- `SttProvider` 어댑터: ENV `STT_PROVIDER` 로 교체 — 현재 `mock`(기본)·`whisper`(OPENAI_API_KEY) 구현. 본부가 RTZR/클로바 확정 시 provider 1개 추가로 전환(계약 무변경).
- 게이트: `consult_recording.sttEnabled`(기본 OFF) + 보호자 동의(sttAllowed, O86) — 동의 없으면 전사 자체를 하지 않음.
