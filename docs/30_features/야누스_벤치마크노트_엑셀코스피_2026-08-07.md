## 0. 이 사이트의 정체

"회사에서 엑셀 보는 척 주식 보기" — 완전한 엑셀 위장 UI(리본·수식바 `=MARKETBRIEF(AUTO)`·시트 탭·셀 선택 흉내) 아래에 시세표(국장·미장·코인)·보유 손익·채팅·게시판·뉴스·AI 브리핑·모의투자·미니앱을 담은 대시보드. **Cloudflare Pages 정적 프론트 + `/api/*` 서버리스(Functions) 백엔드** — 야누스의 "정적/동적 분리" 원칙과 정확히 같은 구조를 상용 수준으로 운영 중이다.

## 1. A급 — 야누스에 바로 넣을 가치가 있는 것 7

**A1. URL 상태 공유(서버 무저장 공유링크)** — 워치리스트+보유내역 전체를 base64url(JSON 압축)로 인코딩해 `/s/...` 링크 하나로 공유. 서버 저장 0, 정적 호스팅만으로 개인화 공유가 성립.
→ 야누스 적용: **두 번째 문 결과 카드 공유**("내 분포 카드 링크로 보내기" — 12월 바이럴 장치), 플래너 템플릿 공유·반 초대 링크, 북패스 서가 공유. janus_score URL 전달 규약의 확장판이라 기존 설계와 충돌 없음. **난이도 하·효과 상.**

**A2. 게스트 디바이스 ID + 회원 이중 identity** — `member_user_id / device_user_id / session token` 3층으로, **로그인 없이도 알림·설정이 서버에 붙고** 가입 시 병합되는 구조.
→ 야누스 적용: 무료 배치표 사용자의 게스트 개인화(저장·알림)를 가입 전에 제공 → "가입해야 잃지 않는다"가 아니라 "이미 쌓인 걸 가입으로 승격"하는 획득 퍼널. W6 런칭의 전환 설계에 직결.

**A3. 가격 알림 패턴 → "컷 알림"** — 종목 검색→목표가/손절가/등락% 조건→서버 알림. UI·API 계약이 단순하고 완성돼 있다.
→ 야누스 킬러 응용: **목표 대학 컷 알림** — 실채점·발표 시즌에 "네 누백이 작년 70%컷 도달/이탈", 원서 D-day, 두 번째 문 재개봉 알림. 능동성 사다리 1단계(동의한 목표 범위의 기한·상태 알림)와 정합. Telegram 연동(이 사이트가 실사용)은 카톡 알림톡 대비 비용 0의 초기 채널 후보.

**A4. 빌드 프로브 + 셀프힐 + 오류 링버퍼** — meta build-id를 fetch로 재확인해 새 배포 감지 시 안내·자동 리로드, 클라이언트 오류 30개 링버퍼+전송, 자산 로드 실패 시 자기복구 배너.
→ 야누스 적용: 배치표·가격지도 등 **정적 티어 빌드의 운영 안전판**으로 그대로. 시즌 트래픽(W9~10) 중 배포 사고의 완충 장치. **난이도 하 — W6 전 이식 권장.**

**A5. 도메인 이중화(차단 대비 미러)** — 공유 UI에 pages.dev(기본)/github.io(**"차단 시 보조"**) 선택지 내장. 회사 방화벽 차단을 제품이 미리 대비.
→ 야누스 적용: 학생의 주 사용 환경이 **학교·학원 PC**라 pages.dev류 차단이 실제 리스크. 무료 배치표에 보조 도메인 미러(github.io 또는 제2 도메인)를 준비하고 공유 링크에 선택지 제공. 도메인 결정(ianus)과 함께 설계.

**A6. 무단 미러 방어** — 호스트네임 해시 화이트리스트로 클론 사이트를 감지해 원본으로 리다이렉트(난독화된 djb2 해시, 지연 실행).
→ 야누스 적용: **무료판 배치표 HTML의 무단 재배포 감지** — 어디가·esteacher 재배포 금지 조건의 기술적 보조 장치로 워터마크와 결합. 완벽 방어는 아니지만(제거 가능) 캐주얼 미러를 원본 트래픽으로 회수한다. 데이터 권리 대응 패키지에 편입 가치.

**A7. 시장 캘린더 정적 내장** — KRX·미국 휴장일·조기폐장을 코드에 상수로 내장해 클라이언트에서 즉시 판정.
→ 야누스 적용: **입시 캘린더 모듈**(모평·수능·원서·발표일)을 동일 패턴의 정적 상수로 — 시즌 앵커·D-day 알림·플래너 시즌 뷰의 공통 데이터 소스. 연 1~2회 갱신이면 충분한 데이터라 정적 내장이 정답.

## 2. B급 — 개념만 차용·변형

- **위장 UI → "환경 스킨"으로 순화**: "몰래 보기" 위장 자체는 야누스 브랜드(정직·신뢰)와 충돌하지만, 그 본질은 "사용 환경에 맞춘 저자극 모드"다. 플래너·데일리의 **독서실 모드**(무음·흑백·미니멀 — availability env와 연동)로 변형 채택. 상담 환경 인지 매칭과 같은 사상.
- **채팅베스트(chat-rank)**: 커뮤니티 베스트 노출 문법 — 야누스 마루 분화 설계 시 참고.
- **모의(paper) 모드**: "성적 없이 예시로 둘러보기" 온보딩 백로그와 동형 — 기존 백로그 유지.
- **드래그 패널 배치(quote-drag·panel-order)**: 플래너 드래그 UX 참고 소스.
- **미니앱·워드게임**: 재미·중독 축은 별도 사업 결정(기존 D) — 기각.

## 3. 야누스가 더 잘할 수 있는 지점 (벤치 대비 우위 확인)

이 사이트는 익명 대중용이라 **개인화 깊이가 얕다**(워치리스트 수준). 야누스는 janus_score·실행 데이터라는 깊은 개인화 축이 있으므로, 같은 패턴(공유 링크·알림·게스트 승격)을 얹었을 때 가치가 훨씬 크다. 반대로 배울 것은 **"가입 전에도 쓸모 있게"**의 집요함 — 이 사이트는 로그인 없이 모든 코어가 돌아간다. 야누스 무료 티어 설계의 기준선으로 삼을 만하다.
