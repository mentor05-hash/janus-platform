# 선생님 선별·수신 설정 벤치마크 — 제안 (2026-07-20)

> 원칙(사장 지시): **기본 노출은 가장 널리 쓰이는 것만, 설정으로 개별맞춤.**
> 조사: 김과외·숨고·콴다과외·설탭·오누이·메가 큐브 (웹 공개자료 기반 — 상세는 아래 표).

## 1. 시장 공통 핵심 (거의 전 서비스 제공)

1. **과목/분야** — 학생 필터·선생님 수신 제한 양측 1순위 축
2. **신뢰지표(대학/인증)** — 필터 제공(김과외·큐브) 또는 풀 자체 검증으로 대체(설탭·오누이)
3. **평점·후기·활동량** — 전 서비스 노출(숨고는 고용횟수, 큐브는 만족도 4.95 마케팅)
4. **가격/방식** — 마켓형은 필터, 플랫폼형(우리 포함)은 정액제로 흡수 → UI 생략 가능

## 2. 차별화 옵션 (일부만 제공)

- 성별·나이·출신고·합격사례 세부 필터(김과외 최다 — 설탭은 의도적 차단)
- **지정 튜터/찜 후 재질문**(오누이·큐브·숨고) — 질문앱 3사 공통 리텐션 장치
- 선생님 시간표·활동지역 기반 수신 제한(숨고·오누이·설탭)
- 요청별 선택 수락(pull — 콴다·큐브·숨고 입찰)
- "지금 접속 중" 필터는 확인된 곳 없음 — 응답속도 SLA 로 대체되는 추세(우리 P5 방향과 일치)

## 3. 우리 현행 대조

| 시장 표준 | 야누스 현행 | 판정 |
|---|---|---|
| 과목 필터 | ✗ 지정 선생님 리스트가 전 과목 혼재 | **갭 — 1순위** |
| 평점·활동량 | ✅ P5 SLA 배지(첫응답·★·답변수) | 완비 |
| 신뢰지표 | 프로필에 있으나 리스트 미표시 | 부분 갭(선택) |
| 가격 | 정액(질문권·크레딧) | 생략 가능 — 표준과 일치 |
| 지정/찜 재질문 | C2 후속문답·continuePref("계속 받을게요")·소프트블록 ✅ / **찜 목록·우선 표시는 없음** | 갭 — 2순위 |
| 선생님 수신 설정 | 이어상담 토글 ✅(O91) / **Q&A 수신 on/off·과목 제한 없음** | 갭 — 3순위 |
| 요청별 선택 수락 | ✅ 공개 큐 선착순 = pull 방식 | 완비 |

## 4. 제안 (기본 최소 + 설정 개별맞춤)

**기본 노출(학생 질문 폼)** — 추가 없이 정리만:
- 지정 리스트를 **폼에서 고른 과목의 선생님 우선 정렬/필터**(신규 F1)
- 기존 SLA 배지 + 💬 이어상담 배지(구현됨) 유지 — 그 외 항목은 노출하지 않음

**상세(접이식/설정) — 자주 쓰는 유저용:**
- F2 **찜한 선생님**: "계속 받을게요" 선택 시 자동 찜 + 리스트 상단 고정(⭐) + 찜만 보기. 소프트블록의 양(+)의 짝 — 테이블 재사용 가능
- F3 **선생님 Q&A 수신 설정**: 질문 수신 on/off(휴가·시험기간) + 수신 과목 제한(profile.subjects 재사용) — 공개 큐·디렉터리·자동배정에 일관 반영

**도입 안 함(근거):** 성별·출신고 필터(설탭도 의도적 차단 — 소규모 풀에서 역효과), 지금 접속 중(시장 부재 — SLA 로 대체), 가격 필터(정액제).
