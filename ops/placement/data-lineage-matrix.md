# 데이터 계보 매트릭스 (O77 — 투트랙·3버전 원천 정책)

> 목적: 배치표 데이터의 **필드별 원천을 태깅**해, 외부 유료 공개본(V3)에 고속 유래가 0건임을
> 문서·게이트(`check_clean_build.py`) 양쪽으로 보증한다. 데이터트랙이 병합 JSON 필드 목록으로 채운다.
> ⚠ 이 문서는 코드 채널(repo) — **실데이터 값·컷 수치는 절대 기입 금지**(C6). 필드명·원천 분류만.

## 1. 3버전 정의 (외부 유료 공개 = V3만)

| 버전 | 정의 | 입력 | audience | 용도 |
|---|---|---|---|---|
| **V1** | 아우구르 적용 전 | 고속+어디가 병합(원값 그대로) | `internal` | 내부 비교 기준선 |
| **V2** | 아우구르 적용(현행) | 고속+어디가 병합 → 엔진 보정 | `internal` | 내부 검증·상담 참고 |
| **V3** | 청정 빌드(이제부터) | **어디가 원본 + 평가원·교육청 공식 + 아우구르** (고속 무입력) | `public` | **외부 유료 공개 유일본** |

- 고속 데이터의 지위: **입력 금지, 내부 벤치마크만**(V3 예측 vs 고속 예측 비교표 — 내부 문서).
- 어디가 재가공분: 타인이 가공한 어디가 2차 가공물은 쓰지 않는다 — **어디가 원본에서 직접 재유도**.
- 플랫폼 강제: manifest `audience:"internal"` → 관리자만 열람(상품 권한으로도 불가), 학생·유료회원에겐 탭 숨김.

## 2. 원천 분류 기준

| 태그 | 의미 | V3 반입 |
|---|---|---|
| `ADIGA` | 어디가(대입정보포털) 원본 직수집 | ✅ (출처 표기) |
| `KICE` | 평가원·교육청 공식(채점자료·표점분포·응시통계) | ✅ (출처 표기) |
| `UNIV` | 대학 모집요강·대교협 공시 | ✅ |
| `AUGUR` | 아우구르 엔진 산출(재적합·LOO·백테스트) — 자체 IP | ✅ |
| `DERIVED` | 자체 파생 지표(relTier·밴드·확률 P 등 — 역산 불가 스케일) | ✅ |
| `GOSOK` | 고속성장 유래(원값·보정치·환산표 포함) | ❌ **V3 금지** — 대체/모델산출/드롭 |
| `GOSOK-D` | 고속 유래를 가공한 2차값(원값 역산 가능성 있음) | ❌ V3 금지(안전측) |

## 3. 필드 매트릭스 (데이터트랙이 채움 — 행 추가)

| 필드명(병합 JSON 기준) | 현 원천 | V3 처리 | 대체 원천 | 상태 |
|---|---|---|---|---|
| (예) `cutNb70` | GOSOK-D | 재유도 | ADIGA 70%컷 + KICE 분포 | ☐ |
| (예) `std2nb` 환산표 | GOSOK | 재유도 | KICE 채점자료 분포 | ☐ |
| (예) `predLine` 예측선 | AUGUR | 유지 | — | ☐ |
| (예) `univ`/`dept`/`track` | ADIGA/UNIV | 유지 | — | ☐ |
| … | | | | |

처리 규칙: `유지`(청정 원천) / `재유도`(공공 원천에서 재계산) / `모델산출`(아우구르가 생성) / `드롭`(V3 미제공).
